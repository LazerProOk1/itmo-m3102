title: Проверь себя: мастер-теорема
description: Параметры $a$, $b$, $f(n)$, дерево рекурсии, геометрическая прогрессия по уровням и три случая.

? Что означает $f(n)$ в $T(n) = a \cdot T(n/b) + f(n)$?
- [x] Работа одного вызова вне рекурсии: разделение задачи и сборка ответа :: Например, слияние в mergesort.
- [ ] Время всех рекурсивных вызовов :: Это $a \cdot T(n/b)$.
- [ ] Размер подзадачи :: Размер подзадачи — $n/b$.

? Какая глубина у дерева рекурсии?
- [ ] $n/b$ :: Это размер подзадачи на первом уровне.
- [x] $\log_b n$ :: На уровне $k$ размер $n/b^k$, листья — при $n/b^k = 1$.
- [ ] $a^n$ :: Число узлов растёт, но глубина логарифмическая.

? Сколько листьев в дереве рекурсии?
- [x] $a^{\log_b n} = n^{\log_b a}$ :: На каждом уровне узлов в $a$ раз больше.
- [ ] $\log_b n$ :: Это число уровней.
- [ ] $n$ всегда :: Только когда $a = b$.

? При $f(n) = n^c$ работа по уровням образует геометрическую прогрессию. Чему равен знаменатель $q$?
- [x] $q = \frac{a}{b^c}$ :: Узлов в $a$ раз больше, а работа в каждом — в $b^c$ раз меньше.
- [ ] $q = \frac{b}{a}$ :: Не учитывает показатель $c$.
- [ ] $q = a \cdot b^c$ :: Работа в узле уменьшается, а не растёт.

? Если $q = \frac{a}{b^c} < 1$, что определяет ответ?
- [x] Работа корневого уровня: $T(n) = \Theta(n^c)$ :: Убывающая прогрессия — сумма порядка первого члена.
- [ ] Число листьев: $\Theta(n^{\log_b a})$ :: Так при $q > 1$.
- [ ] Все уровни поровну: $\Theta(n^c \log n)$ :: Так при $q = 1$.

? $T(n) = 4T(n/2) + n^2$. Какой ответ?
- [ ] $\Theta(n^2)$ :: Это случай $a < b^c$, а здесь $a = b^c$.
- [x] $\Theta(n^2 \log n)$ :: $a = 4 = 2^2 = b^c$ — все уровни дают поровну.
- [ ] $\Theta(n^4)$ :: Показатель $\log_2 4 = 2$, а не 4.

? $T(n) = 3T(n/2) + n$. Чему равен показатель в ответе $\Theta(n^{\log_b a})$?
- [x] $\log_2 3 \approx 1{,}58$ :: $a = 3 > b^c = 2$ — побеждают листья.
- [ ] 1 :: Это $c$; при $a > b^c$ ответ определяют листья.
- [ ] 1,5 :: $\log_2 3$ — не то же самое, что $3/2$.

? Когда классическая формулировка мастер-теоремы неприменима?
- [x] Когда $f(n)$ не имеет вида $\Theta(n^c)$ :: Тогда считают сумму по уровням напрямую или берут общую форму теоремы.
- [ ] Когда $a = 1$ :: Например, $T(n) = T(n/2) + 1$ даёт $\Theta(\log n)$ по случаю $a = b^c$.
- [ ] Когда $b = 2$ :: Это самый частый случай применения.
