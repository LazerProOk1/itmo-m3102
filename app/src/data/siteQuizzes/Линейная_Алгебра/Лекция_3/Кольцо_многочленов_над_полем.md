title: Проверь себя: кольцо многочленов
description: Степень многочлена, кольцо $K[x]$, деление с остатком, теорема Безу, основная теорема алгебры, сопряжённые корни.

? Какие свойства степени многочленов верны?
- [x] $\deg(PQ) = \deg P + \deg Q$ :: Старшие члены перемножаются, а произведение ненулевых коэффициентов поля не ноль.
- [x] $\deg(P + Q) \le \max(\deg P, \deg Q)$ :: Старшие члены могут сократиться.
- [ ] $\deg(P + Q) = \max(\deg P, \deg Q)$ всегда :: $(x^2 + 1) + (-x^2 + x) = x + 1$ — степень 1.

? Чему равна степень нулевого многочлена?
- [ ] 0 :: Степень 0 у ненулевой константы.
- [x] $-\infty$ (по соглашению) :: Так сохраняется правило $\deg(PQ) = \deg P + \deg Q$.
- [ ] 1 :: Нулевой многочлен не линейный.

? Что гарантирует теорема о делении с остатком при $B(x) \ne 0$?
- [x] Существуют единственные $Q(x)$ и $R(x)$: $A = BQ + R$, причём $\deg R < \deg B$ :: Как деление чисел с остатком.
- [ ] Остаток всегда равен нулю :: Только если $B$ делит $A$.
- [ ] Частное и остаток определены неоднозначно :: Единственность доказывается отдельно.

? Найдите остаток от деления $P(x) = x^3 - 2x + 5$ на $(x - 2)$. Введите число.
= 9
correct: По теореме Безу остаток равен $P(2) = 8 - 4 + 5 = 9$.
wrong: Теорема Безу: остаток от деления на $(x - c)$ равен $P(c)$. Здесь $P(2) = 2^3 - 2 \cdot 2 + 5 = 9$.

? Когда $c$ — корень многочлена $P(x)$?
- [x] Когда $P(x)$ делится на $(x - c)$ без остатка :: Следствие теоремы Безу.
- [ ] Когда $P(x)$ делится на $(x + c)$ :: Тогда корнем был бы $-c$.
- [ ] Когда $c$ — старший коэффициент :: Корень — значение переменной, а не коэффициент.

? Что утверждает основная теорема алгебры (теорема Гаусса)?
- [x] Любой многочлен из $\mathbb{C}[x]$ степени $\ge 1$ имеет хотя бы один корень в $\mathbb{C}$ :: Отсюда разложение на $n$ линейных множителей.
- [ ] Любой многочлен из $\mathbb{R}[x]$ имеет вещественный корень :: $x^2 + 1$ — контрпример.
- [ ] У многочлена степени $n$ ровно $n$ различных корней :: Корни могут быть кратными.

? У многочлена с вещественными коэффициентами есть корень $2 + 3i$. Что ещё обязательно является корнем?
- [x] $2 - 3i$ :: Невещественные корни идут сопряжёнными парами.
- [ ] $-2 + 3i$ :: Сопряжение меняет знак мнимой части, а не вещественной.
- [ ] $3 + 2i$ :: Это другое число.

? На какие множители раскладывается любой многочлен из $\mathbb{R}[x]$?
- [x] Линейные и неприводимые квадратичные :: Каждая пара сопряжённых корней даёт квадратный трёхчлен с вещественными коэффициентами.
- [ ] Только линейные :: $x^2 + 1$ над $\mathbb{R}$ на линейные не раскладывается.
- [ ] Только квадратичные :: Вещественные корни дают линейные множители.
