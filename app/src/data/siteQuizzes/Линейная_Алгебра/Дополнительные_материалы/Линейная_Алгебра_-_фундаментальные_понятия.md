title: Проверь себя: фундаментальные понятия линейной алгебры
description: Векторы и базис, линейные комбинации и оболочка, зависимость, линейные преобразования, умножение матриц и определитель.

? Что такое координаты вектора с точки зрения базиса?
- [x] Скаляры, на которые умножают базисные векторы, чтобы в сумме получить вектор :: $\vec v = x\hat\imath + y\hat\jmath$.
- [ ] Длина и угол вектора :: Это полярное описание, а не координаты в базисе.
- [ ] Точки начала и конца стрелки :: Начало всегда в $(0;0)$.

? Что такое линейная оболочка двух векторов?
- [x] Множество всех их линейных комбинаций :: Обычно на плоскости — вся плоскость.
- [ ] Отрезок между их концами :: Это лишь малая часть комбинаций.
- [ ] Их сумма :: Сумма — одна из комбинаций, а оболочка — все.

? Когда векторы линейно зависимы?
- [x] Когда один из них можно убрать, не уменьшив линейную оболочку :: Он выражается через остальные.
- [ ] Когда они разной длины :: Длина не влияет на зависимость.
- [ ] Когда они перпендикулярны :: Перпендикулярные ненулевые векторы как раз независимы.

? Какие свойства сохраняет линейное преобразование?
- [x] Прямые остаются прямыми :: Иначе преобразование нелинейное.
- [x] Начало координат остаётся на месте :: Сдвиг — не линейное преобразование.
- [x] Линии сетки остаются параллельными и равноудалёнными :: Поэтому достаточно знать, куда переходят базисные векторы.
- [ ] Длины векторов не меняются :: Растяжение тоже линейное преобразование.

? В произведении $M_2 M_1$ какое преобразование применяется первым?
- [x] $M_1$ — правая матрица :: Композиция читается справа налево, как $f(g(x))$.
- [ ] $M_2$ — левая матрица :: Левая применяется последней.
- [ ] Порядок не важен :: Умножение матриц не коммутативно.

? Какие свойства у умножения матриц?
- [x] Ассоциативно: $(AB)C = A(BC)$ :: Это одна и та же цепочка преобразований.
- [ ] Коммутативно: $AB = BA$ :: Поворот, затем сдвиг-скос — не то же, что наоборот.

? Чему равен определитель матрицы $\begin{pmatrix} 3 & 1 \\ 2 & 4 \end{pmatrix}$? Введите число.
= 10
correct: $ad - bc = 3 \cdot 4 - 1 \cdot 2 = 10$: площади растягиваются в 10 раз.
wrong: Для $2 \times 2$: $\det = ad - bc = 3 \cdot 4 - 1 \cdot 2 = 12 - 2 = 10$.

? Что означает определитель, равный нулю?
- [x] Преобразование сплющивает пространство — уменьшается число измерений :: Например, плоскость схлопывается в прямую.
- [ ] Преобразование ничего не меняет :: Тождественное преобразование имеет определитель 1.
- [ ] Ориентация пространства меняется на обратную :: Это отрицательный определитель.
