title: Проверь себя: поле комплексных чисел
description: Определение через пары, мнимая единица, алгебраическая и тригонометрическая формы, сопряжение, формула Муавра, корни и формула Эйлера.

? Как умножаются пары в определении $\mathbb{C}$?
- [x] $(a, b) \cdot (c, d) = (ac - bd,\ ad + bc)$ :: «Перекрёстное» правило — именно из него следует $i^2 = -1$.
- [ ] $(a, b) \cdot (c, d) = (ac,\ bd)$ :: Покомпонентное умножение не даёт поля: $(1,0)\cdot(0,1) = (0,0)$.
- [ ] $(a, b) \cdot (c, d) = (ac + bd,\ ad - bc)$ :: Знаки перепутаны.

? Чему равна мнимая часть числа $z = 3 - 4i$?
- [ ] $-4i$ :: Мнимая часть — вещественное число, без $i$.
- [x] $-4$ :: $\operatorname{Im} z$ — коэффициент при $i$.
- [ ] $4$ :: Знак коэффициента сохраняется.

? Чему равно $|3 + 4i|$? Введите число.
= 5
correct: $|z| = \sqrt{3^2 + 4^2} = 5$.
wrong: Модуль — длина вектора $(a, b)$: $|3 + 4i| = \sqrt{9 + 16} = \sqrt{25} = 5$.

? Что происходит при умножении комплексных чисел в тригонометрической форме?
- [x] Модули перемножаются, аргументы складываются :: Поэтому умножение на $i$ — поворот на $90^\circ$.
- [ ] Модули складываются, аргументы перемножаются :: Наоборот.
- [ ] Перемножаются и модули, и аргументы :: Углы складываются.

? Формула Муавра для $z = r(\cos\varphi + i\sin\varphi)$:
- [x] $z^n = r^n(\cos n\varphi + i \sin n\varphi)$ :: Модуль в степень, аргумент умножается на $n$.
- [ ] $z^n = r^n(\cos^n\varphi + i \sin^n\varphi)$ :: Степени тригонометрических функций — ошибка.
- [ ] $z^n = nr(\cos\varphi + i\sin\varphi)$ :: Так не возводят в степень.

? Сколько различных значений у $\sqrt[4]{z}$ для $z \ne 0$? Введите число.
= 4
correct: Корней $n$-й степени ровно $n$ — вершины правильного $n$-угольника на окружности радиуса $\sqrt[n]{|z|}$.
wrong: Аргумент определён с точностью до $2\pi k$, поэтому $\frac{\varphi + 2\pi k}{4}$ даёт 4 разных угла при $k = 0, 1, 2, 3$.

? Какие утверждения о сопряжении верны?
- [x] $\overline{z_1 + z_2} = \overline{z_1} + \overline{z_2}$ :: Сопряжение согласовано со сложением.
- [x] $z \cdot \overline{z} = |z|^2$ — вещественное число :: На этом основано деление комплексных чисел.
- [ ] $\overline{z} = -z$ :: Сопряжение меняет знак только у мнимой части.

? Почему на $\mathbb{C}$ нет привычного «больше/меньше»?
- [x] Нельзя ввести порядок, согласованный с операциями: тогда $i^2 = -1 < 0$ противоречит правилам знаков :: Поэтому сравнивают только модули.
- [ ] Потому что комплексных чисел бесконечно много :: Вещественных тоже бесконечно много, а порядок есть.
- [ ] Порядок есть: сравнивают вещественные части :: Это не порядок поля.

? Формула Эйлера:
- [x] $e^{i\varphi} = \cos\varphi + i\sin\varphi$ :: Отсюда показательная форма $z = re^{i\varphi}$.
- [ ] $e^{i\varphi} = \cos\varphi - i\sin\varphi$ :: Это $e^{-i\varphi}$.
- [ ] $e^{\varphi} = \cos\varphi + \sin\varphi$ :: Без $i$ формула неверна.
