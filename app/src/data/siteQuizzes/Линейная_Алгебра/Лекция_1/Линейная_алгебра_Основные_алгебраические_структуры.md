title: Проверь себя: группы, кольца, поля
description: Бинарная операция и замкнутость, аксиомы группы, абелевы и неабелевы группы, перестановки, кольца и делители нуля, поле.

? Почему вычитание не является бинарной операцией на $\mathbb{N}$?
- [x] Нарушается замкнутость: $2 - 5 \notin \mathbb{N}$ :: Результат операции обязан лежать в том же множестве.
- [ ] Вычитание некоммутативно :: Коммутативность от бинарной операции не требуется.
- [ ] У вычитания нет нейтрального элемента :: Для операции это не нужно, нужно для группы.

? Какие аксиомы входят в определение группы $(G, *)$?
- [x] Ассоциативность :: $(a * b) * c = a * (b * c)$.
- [x] Существование нейтрального элемента :: $a * e = e * a = a$.
- [x] Существование обратного для каждого элемента :: $a * a^{-1} = e$.
- [ ] Коммутативность :: Это дополнительное свойство: такие группы называют абелевыми.

? Является ли группа диэдра (симметрии квадрата) абелевой?
- [ ] Да, все группы абелевы :: Коммутативность — не следствие аксиом группы.
- [x] Нет: «повернуть, затем отразить» не то же, что «отразить, затем повернуть» :: Пример неабелевой группы.
- [ ] Это вообще не группа :: Композиция симметрий — группа: есть тождественная симметрия и обратные.

? Какое отображение называют биекцией?
- [x] Одновременно инъекцию (разные переходят в разные) и сюръекцию (каждый элемент — чей-то образ) :: Взаимно однозначное соответствие.
- [ ] Любое отображение множества в себя :: Например, $f(x) = 0$ не биекция.
- [ ] Только тождественное отображение :: Тождественное — частный случай.
explain: Перестановка — биекция множества на себя; перестановки $n$ элементов с композицией образуют группу $S_n$.

? Сколько элементов в симметрической группе $S_3$? Введите число.
= 6
correct: Перестановок трёх элементов $3! = 6$.
wrong: Элементы $S_3$ — все перестановки трёх элементов, их $3! = 3 \cdot 2 \cdot 1 = 6$.

? Как читается композиция $f \circ g$?
- [x] Сначала $g$, потом $f$ :: Как в записи $f(g(x))$.
- [ ] Сначала $f$, потом $g$ :: Частая ошибка: запись читается справа налево.

? Какие элементы кольца $\mathbb{Z}_6$ — делители нуля?
- [x] 2 :: $2 \cdot 3 = 6 \equiv 0$.
- [x] 3 :: $3 \cdot 2 \equiv 0$ и $3 \cdot 4 = 12 \equiv 0$.
- [x] 4 :: $4 \cdot 3 = 12 \equiv 0$.
- [ ] 5 :: 5 обратим: $5 \cdot 5 = 25 \equiv 1$.

? Почему $\mathbb{Z}_6$ не поле, а $\mathbb{Z}_7$ — поле?
- [x] Модуль 7 простой, поэтому делителей нуля нет и все ненулевые элементы обратимы; 6 составное :: Поле $\mathbb{Z}_p$ — только при простом $p$.
- [ ] В $\mathbb{Z}_6$ умножение некоммутативно :: Оно коммутативно, проблема в обратимости.
- [ ] В $\mathbb{Z}_7$ больше элементов :: Дело не в количестве, а в простоте модуля.

? Зачем в аксиомах поля отдельное требование $0 \ne 1$?
- [x] Чтобы исключить вырожденное «поле» из одного элемента $\{0\}$ :: Там остальные аксиомы формально выполняются.
- [ ] Чтобы умножение было коммутативным :: Это отдельная аксиома.
- [ ] Чтобы $1 + 1 \ne 0$ :: В $\mathbb{Z}_2$ как раз $1 + 1 = 0$, и это поле.
