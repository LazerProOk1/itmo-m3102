title: Проверь себя: вложенные отрезки, точные грани, пределы
description: Принцип Кантора, несчётность континуума, супремум и инфимум, определение предела и его свойства, бесконечно малые.

? Что гарантирует теорема Кантора о вложенных отрезках?
- [x] У системы вложенных отрезков есть общая точка :: Доказательство опирается на аксиому Дедекинда.
- [x] Если длины отрезков стремятся к нулю, общая точка единственна :: Две разные точки дали бы длины $\ge d > 0$.
- [ ] Общая точка есть и у вложенных интервалов $(0; \frac1n)$ :: У интервалов её может не быть: $\bigcap (0; \frac1n) = \varnothing$.

? Что такое континуум $\mathfrak{c}$?
- [x] Мощность отрезка $[0; 1]$ :: Теорема Кантора: $\mathfrak{c} > |\mathbb{N}|$.
- [ ] Мощность $\mathbb{Q}$ :: $\mathbb{Q}$ счётно.
- [ ] Наибольшая из мощностей :: Наибольшей мощности нет: булеан всегда мощнее.

? Число $M$ — супремум множества $E$. Что это значит?
- [x] $M$ — верхняя граница $E$, и для любого $\varepsilon > 0$ есть $x \in E$ с $x > M - \varepsilon$ :: Наименьшая из верхних границ.
- [ ] $M$ — наибольший элемент $E$ :: Супремум может не лежать в $E$: $\sup(0; 1) = 1$.
- [ ] $M$ — любая верхняя граница :: Нужна наименьшая.

? Чему равен $\sup\{1 - \frac1n : n \in \mathbb{N}\}$? Введите число.
= 1
correct: Все члены меньше 1, и они сколь угодно близко подходят к 1 — но сама 1 в множество не входит.
wrong: Каждый элемент $1 - \frac1n < 1$, а для любого $\varepsilon$ найдётся $n > \frac1\varepsilon$ с $1 - \frac1n > 1 - \varepsilon$. Значит, $\sup = 1$.

? Какие множества обязательно имеют супремум?
- [x] Непустое ограниченное сверху подмножество $\mathbb{R}$ :: Теорема существования супремума.
- [ ] Пустое множество :: У $\varnothing$ точных граней нет.
- [ ] Непустое неограниченное сверху множество :: Например, у $\mathbb{N}$ в $\mathbb{R}$ супремума нет.

? Определение предела последовательности:
- [x] $\forall \varepsilon > 0\ \exists N\ \forall n > N: |x_n - a| < \varepsilon$ :: Все члены после $N$ — в $\varepsilon$-окрестности $a$.
- [ ] $\exists \varepsilon > 0\ \forall N\ \exists n > N: |x_n - a| < \varepsilon$ :: Так описывают, что $a$ — лишь точка, к которой члены иногда подходят.
- [ ] $\forall n: |x_n - a| < \varepsilon$ :: Без кванторов по $\varepsilon$ и $N$ это не определение.

? Какие свойства сходящихся последовательностей доказаны в лекции?
- [x] Предел единственен :: Члены не могут одновременно быть в двух непересекающихся окрестностях.
- [x] Сходящаяся последовательность ограничена :: Вне окрестности предела конечное число членов.
- [x] Если $a > 0$, то с некоторого номера $x_n > a/2$ :: Сохранение знака.
- [ ] Ограниченная последовательность сходится :: $(-1)^n$ ограничена, но расходится.

? Что такое бесконечно малая последовательность?
- [x] Последовательность с пределом 0 :: $\forall \varepsilon\ \exists N\ \forall n > N: |\alpha_n| < \varepsilon$.
- [ ] Последовательность из очень маленьких чисел :: Например, $0{,}001$ — константа, она не бесконечно малая.
- [ ] Убывающая последовательность :: $1 + \frac1n$ убывает к 1, а не к 0.
