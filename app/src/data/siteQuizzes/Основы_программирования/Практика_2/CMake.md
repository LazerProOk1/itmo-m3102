title: Проверь себя: CMake и этапы сборки
description: Структура проекта на CMake, препроцессинг, компиляция, линковка, таргеты и файловые потоки.

? В каком порядке идут этапы сборки C++-программы?
- [x] Препроцессинг → компиляция → линковка :: Сначала разворачиваются директивы, потом каждый `.cpp` компилируется отдельно, потом всё собирается вместе.
- [ ] Компиляция → препроцессинг → линковка :: Директивы `#include` должны быть развёрнуты до компиляции.
- [ ] Линковка → компиляция → препроцессинг :: Линковать нечего, пока нет объектных файлов.

? Что делает препроцессор с `#include "func.h"`?
- [x] Подставляет содержимое файла на место директивы :: Буквально вставляет текст.
- [ ] Компилирует `func.h` в объектный файл :: Заголовки не компилируются отдельно.
- [ ] Связывает программу с библиотекой :: Это задача линковщика.

? Чем объявление функции отличается от определения?
- [x] Объявление сообщает сигнатуру, определение даёт тело функции :: `int f(int);` — объявление, `int f(int x) { return x; }` — определение.
- [ ] Ничем, это синонимы :: Это частая путаница.
- [ ] Определение пишут в `.h`, объявление — в `.cpp` :: Обычно наоборот.

? Функцию объявили в заголовке и вызвали, но нигде не определили. На каком этапе будет ошибка?
- [ ] Препроцессинг :: Заголовок успешно подставится.
- [ ] Компиляция :: Компилятору хватает объявления — он оставит заглушку.
- [x] Линковка :: Линковщик не найдёт адрес для заглушки: undefined reference.

? Что оставляет компилятор на месте вызова функции из другого `.cpp`-файла?
- [x] Заглушку — имя функции без адреса, адрес подставит линковщик :: Каждый `.cpp` компилируется независимо.
- [ ] Копию тела функции :: Тела функции в этом файле нет.
- [ ] Ошибку компиляции :: Объявления достаточно.

? Что делает `target_link_libraries(hello PUBLIC lib)`?
- [x] Говорит линковщику собрать исполняемый файл `hello` вместе с библиотекой-таргетом `lib` :: Тогда вызовы из `lib` получат адреса.
- [ ] Добавляет папку `lib` в пути поиска заголовков :: Это делает `target_include_directories`.
- [ ] Создаёт новый исполняемый файл `lib` :: Исполняемые файлы объявляются через `add_executable`.

? Какой класс нужен, чтобы читать числа из файла `input.txt`?
- [x] `std::ifstream` :: i — input: данные идут из файла в программу.
- [ ] `std::ofstream` :: Он для записи.
- [ ] `std::cin` :: Это стандартный ввод, а не файл.
