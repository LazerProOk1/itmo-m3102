title: Проверь себя: множества
description: Предикат принадлежности, включение и пустое множество, равенство через два включения, операции, де Морган, булеан и декартово произведение.

? Почему $\varnothing \subseteq A$ для любого $A$?
- [x] $\forall x.\, (x \in \varnothing \to x \in A)$: посылка всегда ложна, импликация истинна :: Вакуумная истинность.
- [ ] Потому что $\varnothing \in A$ для любого $A$ :: Принадлежность и включение — разные вещи; $\varnothing \in A$ верно не всегда.
- [ ] Это аксиома, её нельзя доказать :: Это следует из определения включения.

? Пусть $B = \{a, \{b\}\}$. Что верно?
- [x] $a \in B$ :: $a$ — прямой элемент.
- [x] $\{b\} \in B$ :: Множество $\{b\}$ — тоже прямой элемент.
- [ ] $b \in B$ :: $b$ лежит внутри $\{b\}$, а принадлежность не «заглядывает» во вложенные множества.
- [x] $\{a\} \subseteq B$ :: Единственный элемент $\{a\}$ — это $a$, и он лежит в $B$.

? Чему равна мощность $\{1, 2, 2, 3, 1\}$? Введите число.
= 3
correct: Повторения не учитываются: это $\{1, 2, 3\}$.
wrong: Множество — набор **различных** объектов, повторения не считаются: $\{1, 2, 2, 3, 1\} = \{1, 2, 3\}$, мощность 3.

? Каким стандартным приёмом доказывают равенство множеств $A = B$?
- [x] Доказывают два включения: $A \subseteq B$ и $B \subseteq A$ :: Это теорема 1.
- [ ] Рисуют диаграмму Венна :: Диаграмма помогает найти контрпример, но не доказывает тождество.
- [ ] Сравнивают мощности :: Равные мощности не означают равенства множеств.

? Каким операциям над множествами соответствуют логические связки?
- [x] $\cup$ — дизъюнкция, $\cap$ — конъюнкция, дополнение — отрицание :: Поэтому законы логики переносятся на множества.
- [ ] $\cup$ — конъюнкция, $\cap$ — дизъюнкция :: Наоборот: $x \in A \cup B \iff x \in A \vee x \in B$.
- [ ] $\setminus$ — импликация :: Разность — это $x \in A \wedge x \notin B$.

? Чему равна симметрическая разность $A \mathbin{\triangle} B$?
- [x] $(A \cup B) \setminus (A \cap B)$ :: Элементы ровно одного из множеств — аналог xor.
- [ ] $A \setminus B$ :: Это обычная разность, она несимметрична.
- [ ] $A \cap B$ :: Пересечение — как раз то, что из $A \cup B$ выкидывается.

? Чему равно $A \setminus (B \cup C)$?
- [x] $(A \setminus B) \cap (A \setminus C)$ :: Теорема 5: убрать и $B$, и $C$.
- [ ] $(A \setminus B) \cup (A \setminus C)$ :: Контрпример: $A = \{1,2,3\}$, $B = \{2\}$, $C = \{3\}$.
- [ ] $A \setminus B \setminus C \cup A$ :: Разность нельзя раскрывать как вычитание чисел.

? У множества 5 элементов. Сколько у него подмножеств? Введите число.
= 32
correct: $|\mathcal{P}(A)| = 2^5 = 32$.
wrong: Для каждого из 5 элементов независимо решаем, брать его или нет: $2^5 = 32$ подмножества, считая $\varnothing$ и само $A$.

? $|A| = 3$, $|B| = 4$. Чему равно $|A \times B|$?
- [x] 12 :: $|A \times B| = |A| \cdot |B|$.
- [ ] 7 :: Это была бы мощность $A \cup B$ для непересекающихся множеств.
- [ ] 81 :: $4^3$ — число функций из $A$ в $B$, а не пар.
explain: Элементы $A \times B$ — упорядоченные пары $(a, b)$: 3 способа выбрать $a$ и 4 способа выбрать $b$.
