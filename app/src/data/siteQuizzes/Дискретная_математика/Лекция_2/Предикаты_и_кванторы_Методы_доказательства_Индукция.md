title: Проверь себя: кванторы, доказательства, индукция
description: Предикаты и предметная область, отрицание и порядок кванторов, ограниченные кванторы, методы доказательства и индукция.

? Что нужно, чтобы опровергнуть $\forall x.\, P(x)$?
- [x] Найти один $x$, для которого $P(x)$ ложно :: Это контрпример.
- [ ] Показать, что $P(x)$ ложно для всех $x$ :: Так опровергают $\exists x.\, P(x)$.
- [ ] Перебрать все $x$ и проверить :: Достаточно одного контрпримера.

? Чему равно $\neg\big(\forall x.\, P(x)\big)$?
- [x] $\exists x.\, \neg P(x)$ :: Квантор меняется, предикат отрицается.
- [ ] $\forall x.\, \neg P(x)$ :: Ошибка: не поменяли тип квантора.
- [ ] $\exists x.\, P(x)$ :: Ошибка: забыли отрицать предикат.

? В формуле $\forall x.\, (x^2 \ge y)$ какие переменные свободные?
- [ ] $x$ :: По $x$ стоит квантор — она связанная.
- [x] $y$ :: По $y$ квантора нет — формула остаётся предикатом от $y$.
- [ ] Обе :: $x$ связана квантором $\forall$.

? Какое утверждение сильнее?
- [x] $\exists y.\, \forall x.\, P(x, y)$ :: Один $y$ подходит сразу всем $x$.
- [ ] $\forall x.\, \exists y.\, P(x, y)$ :: Здесь для каждого $x$ свой $y$ — это слабее.
explain: Из $\exists y\, \forall x$ следует $\forall x\, \exists y$, но не наоборот: у каждого человека есть мать, но нет одной матери на всех.

? Как развернуть ограниченный квантор $\exists x \in A.\, P(x)$?
- [x] $\exists x.\, \big((x \in A) \wedge P(x)\big)$ :: Под $\exists$ — конъюнкция.
- [ ] $\exists x.\, \big((x \in A) \to P(x)\big)$ :: Частая ошибка: такая формула истинна даже при пустом $A$.
- [ ] $\forall x.\, \big((x \in A) \to P(x)\big)$ :: Это развёртка $\forall x \in A$.

? Как формализовать «$P(x)$, только если $Q(x)$»?
- [x] $P(x) \to Q(x)$ :: $Q$ — необходимое условие для $P$.
- [ ] $Q(x) \to P(x)$ :: Это «$P(x)$, если $Q(x)$».
- [ ] $P(x) \leftrightarrow Q(x)$ :: Это «тогда и только тогда».

? Какое утверждение эквивалентно $P \to Q$?
- [x] $\neg Q \to \neg P$ (контрапозиция) :: Её можно доказывать вместо исходного.
- [ ] $Q \to P$ (обратное) :: Обратное утверждение не эквивалентно исходному.
- [ ] $\neg P \to \neg Q$ :: Это противоположное, оно эквивалентно обратному, а не исходному.

? Чем сильная индукция отличается от обычной?
- [x] В переходе можно опираться на $P(k)$ для всех $k \le n$, а не только на $P(n)$ :: $\big(\forall k \le n.\, P(k)\big) \to P(n+1)$.
- [ ] Ей не нужна база :: База нужна, как и в обычной индукции.
- [ ] Она доказывает утверждения для вещественных $n$ :: Индукция работает на натуральных числах.

? У каких множеств нет наименьшего элемента?
- [x] $\mathbb{Z}$ :: Для любого целого есть меньшее.
- [x] $\{x \in \mathbb{Q} : x > 0\}$ :: Для любого положительного рационального есть меньшее положительное.
- [ ] $\{5, 8, 13\}$ :: Наименьший — 5.
- [ ] Любое непустое подмножество $\mathbb{N}$ :: У них наименьший элемент есть всегда — это принцип наименьшего числа.
