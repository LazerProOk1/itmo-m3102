title: Проверь себя: бинарные отношения
description: Определение и представления отношений, свойства, эквивалентность и классы, обратное отношение, композиция, степени и замыкания.

? Что такое бинарное отношение между $A$ и $B$?
- [x] Любое подмножество $R \subseteq A \times B$ :: Пара $\langle a, b \rangle \in R$ значит «$a$ связано с $b$».
- [ ] Функция из $A$ в $B$ :: Функция — частный случай отношения.
- [ ] Пара множеств $\langle A, B \rangle$ :: Отношение — множество пар элементов, а не пара множеств.

? Почему рефлексивность, симметричность и транзитивность определяют для однородных отношений ($R \subseteq A \times A$)?
- [x] В определениях элемент встаёт и на первое, и на второе место пары — значит, обе компоненты из одного множества :: Например, $\langle a, a \rangle$ требует $a \in A$ и $a \in B$.
- [ ] Для неоднородных отношений они всегда выполняются :: Нет, они там просто не имеют смысла.
- [ ] Потому что матрица неоднородного отношения пустая :: Матрица просто прямоугольная.

? Какие утверждения верны?
- [x] Равенство $\mathrm{id}_A$ симметрично и антисимметрично одновременно :: Симметричность и антисимметричность — не противоположности.
- [x] Асимметричность = антисимметричность + иррефлексивность :: Пример: строгий порядок $<$.
- [x] Тотальное отношение всегда рефлексивно :: При $a = b$ из $aRb \vee bRa$ получаем $aRa$.
- [ ] Иррефлексивность — то же самое, что «не рефлексивно» :: Иррефлексивность сильнее: ни одной петли.

? Какое отношение на $\mathbb{N}$ является отношением эквивалентности?
- [x] «$a$ и $b$ дают одинаковый остаток при делении на 3» :: Рефлексивно, симметрично и транзитивно.
- [ ] Делимость $a \mid b$ :: Она не симметрична: $2 \mid 4$, но $4 \nmid 2$.
- [ ] $a < b$ :: Не рефлексивно и не симметрично.
explain: Эквивалентность — рефлексивное, симметричное и транзитивное отношение; она разбивает множество на классы.

? Сравнимость по модулю 3 на $\{0, 1, \dots, 8\}$. Сколько элементов в классе эквивалентности числа 4? Введите число.
= 3
correct: $[4] = \{1, 4, 7\}$ — все числа с остатком 1.
wrong: Класс $[4]$ — все числа с тем же остатком 1 при делении на 3: $\{1, 4, 7\}$, то есть 3 элемента.

? Коммутативна ли композиция отношений?
- [ ] Да, $R \mathbin{;} S = S \mathbin{;} R$ всегда :: Ассоциативность не означает коммутативность.
- [x] Нет, в общем случае $R \mathbin{;} S \ne S \mathbin{;} R$ :: Например, $R = \{\langle 1,2 \rangle\}$, $S = \{\langle 2,3 \rangle\}$: одна композиция даёт $\langle 1,3 \rangle$, другая пуста.

? Что описывает степень $R^n$ однородного отношения?
- [x] Достижимость ровно за $n$ шагов по графу отношения :: Например, для «родитель» $R^2$ — бабушки и дедушки.
- [ ] Число пар в $R$, возведённое в степень $n$ :: Степень — это композиция, а не арифметика.
- [ ] Достижимость не более чем за $n$ шагов :: «Не более» даёт объединение степеней.

? Отношение $\{\langle 1,2 \rangle, \langle 2,3 \rangle, \langle 3,4 \rangle\}$. Почему для транзитивного замыкания мало одного прохода «добавить $aRc$ для каждой пары $aRb$, $bRc$»?
- [x] Новые пары образуют новые цепочки: после $\langle 1,3 \rangle$ появится $\langle 1,4 \rangle$ только на втором проходе :: Повторяют до стабилизации или используют алгоритм Уоршелла.
- [ ] Один проход добавляет лишние пары :: Он добавляет только нужные, но не все.
- [ ] Транзитивное замыкание нельзя построить для конечного множества :: Можно, оно конечно.

? Как устроены циклы в алгоритме Уоршелла?
- [x] Внешний цикл — по промежуточной вершине $k$, внутренние — по парам $\langle i, j \rangle$ :: Тогда на шаге $k$ можно использовать рёбра, добавленные раньше.
- [ ] Внешний цикл по $i$, потом $j$, внутренний по $k$ :: С таким порядком замыкание получится не всегда.
- [ ] Порядок циклов не важен :: Важен: $k$ обязательно внешний.
