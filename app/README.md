# М3102

Расписание, дедлайны, ДЗ, конспекты и тесты группы М3102 (ИТМО) в одном месте.

[![CI](https://img.shields.io/github/actions/workflow/status/LazerProOk1/itmo-m3102/deploy-pages.yml?branch=react-app&label=CI)](https://github.com/LazerProOk1/itmo-m3102/actions/workflows/deploy-pages.yml)
[![Сайт](https://img.shields.io/badge/%D1%81%D0%B0%D0%B9%D1%82-lazerprook1.github.io-5b6cf9)](https://lazerprook1.github.io/itmo-m3102/)

</div>

Сайт работает в браузере без сервера и регистрации, ставится как приложение и открывается без интернета.
Данные берутся из репозиториев группы на GitHub, личное хранится только на устройстве.

## Возможности

- **Расписание** — неделя по часам на ПК и список по дням на телефоне, чётные недели, переносы и замены. В карточке
  пары — ДЗ к ней и её конспект («Лекция 3» — третья лекция по предмету).
- **Главная** — блоки можно переставить и скрыть, выбрать плотность и страницу, которая открывается при запуске.
- **Календарь** — пары, свои события, дедлайны группы и ДЗ в день сдачи. Подписка для Google и Apple Календаря
  обновляется сама.
- **Дедлайны** — сроки и общая очередь на сдачу через GitHub Issues; у каждого — предмет, конспекты и лабораторные.
- **Предмет** — всё в одном месте: следующая пара, ближайший срок, тесты и «Перед контрольной», преподаватели,
  баллы, дедлайны и ДЗ группы, конспекты последних занятий, свой план, материалы и ссылки.
- **Конспекты группы** — предмет → папка занятия, читалка с формулами, схемами и оглавлением, PDF, закладки
  и пометки в тексте. Под заголовком — когда была пара к конспекту и когда следующая. «Скачать PDF» с водяным
  знаком сайта и печать без обрезанных формул.
- **Схемы** — графы, деревья, массивы с пошаговым выполнением кода и редактор, где узлы двигаются мышью.
- **Тесты** — к конспектам, с повторением ошибок через 1, 3, 7 и 14 дней и режимом экзамена. Правильный ответ
  после ошибки — по кнопке, в конце — разбор всех своих ответов.
- **Поиск** (`Ctrl+K`) — по тексту всех конспектов, включая PDF и подписи схем; слова в любом порядке; фильтры
  по типу и предмету; быстрые действия (синхронизация, тема, «Перед контрольной»). Горячие клавиши — по `?`.
- **Личное** — учебный план, заметки и отметки «сделано» только в этом браузере.
- **Работа без интернета** — в настройках одной кнопкой: PDF и картинки конспектов, учебники и лабораторные
  группы на устройство, с размером заранее и занятым местом; дальше обновляется само после синхронизации.
- **Для ИИ** — все конспекты предмета одним Markdown-файлом, чтобы отдать ChatGPT или Claude.
- **Два оформления** — кнопка «Переключить стиль» в шапке меняет оформление: классическое (статический сайт группы, в корне адреса и репозитория) или современное (это приложение, `/app/`); данные у обоих общие.
- **Lo-fi радио** — капсула в углу экрана: лоу-фай, чиллаут, лаунж, джаз, синтвейв и эмбиент для учёбы,
  играет при переходах между страницами.
- **Группа** — студенты с фото и контактами из GitHub, полезные ссылки, все файлы репозитория группы с просмотром,
  мемы. Профиль студента открывается из карточки и из очереди дедлайна: коммиты в репозиторий группы и где он
  стоит в очередях сдачи.
- **Внешний вид** — светлая и тёмная тема, цвет акцента (и свой), фон-сияние, живой фон, скругления; боковое меню
  сворачивается (`Ctrl+B`).
- **Режим редактирования** — отдельная сборка (ветка `react-app-dev`): пары, переносы, события, конспекты, материалы
  и ссылки правятся прямо на сайте, ДЗ и мемы публикуются в репозиторий группы; там же резервная копия данных.
- **Ёжик М3102** — маскот: бегает по шапке главной (а иногда вырывается и носится галопом по всему экрану),
  засыпает, если долго ничего не трогать, сидит в пустых списках, выглядывает, когда закрыто всё, наряжается
  к праздникам. И своя игра — «Ёжик-кувырок».

## Установка как приложение

- Android, Chrome: меню → «Установить приложение».
- iPhone, Safari: «Поделиться» → «На экран „Домой“».
- ПК, Chrome или Edge: значок установки в адресной строке.

Первый раз сайт нужно открыть с интернетом. Дальше он обновляется сам, а без сети показывает сохранённое.

## Конспекты для ИИ

На странице предмета кнопка «Для ИИ» скачивает или копирует один файл: описание курса, оглавление, все конспекты
группы по порядку занятий, текст PDF и ссылки на материалы. ИИ читает всё сразу и не тратит токены
на поиск по сайту. Размер — примерно 50–75 тысяч токенов на предмет.

## Календарь в телефоне

«В календарь» на страницах расписания и календаря. Подписка (`webcal://…/m3102.ics`) — пары с переносами
и заменами, дедлайны и ДЗ группы; файл пересобирается раз в сутки и при каждом обновлении сайта, Apple подтягивает
изменения за несколько часов, Google — до суток. «Скачать .ics» — разовый снимок, в нём ещё свои события и задачи.

## Что дальше

- **Главная «Сегодня».** Короткий ответ на «что мне делать сейчас»: следующая пара и что взять, горящие сроки,
  что повторить, — с учётом выбранных на главной блоков.
- **Мобильная версия.** Жесты в читалке, виджет «следующая пара», уведомления о сроках от установленного приложения.
- **После бэкенда.** Профили «о себе» и пройденные тесты, общие заметки к занятиям.

## Откуда данные

- Конспекты, ДЗ, дедлайны, расписание, ссылки и мемы — [RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102).
- Описания курсов (баллы, преподаватели) лежат в `src/data/courseInfo/`, скопированы из [Kefirleos/itmo-vault](https://github.com/Kefirleos/itmo-vault) (1 поток).
  Конспекты 1 потока на сайте не показываются: в «Конспектах» только конспекты группы.
- Очередь на сдачу — GitHub Issues репозитория группы.

Синхронизация идёт при открытии сайта, не чаще раза в 10 минут, и по кнопке в шапке. Без токена у GitHub API
лимит 60 запросов в час на сеть.

Личное (отметки, учебный план, заметки, пометки, результаты тестов) лежит в `localStorage` и не покидает браузер.
План сервера со входом через ITMO ID — в [docs/BACKEND_PLAN.md](../docs/BACKEND_PLAN.md).

## Разработка

Это приложение (современное оформление); в корне репозитория — классический сайт группы, оба описаны в [корневом README](../README.md):

```bash
cd app
npm install
npm run dev          # http://localhost:5173
npm test             # юнит-тесты
npm run test:e2e     # тесты в браузере
npm run build
```

React, TypeScript, Vite, Zustand. Пуш в `react-app` проверяется в CI (форматирование, тесты, размер сборки,
Lighthouse) и публикуется на GitHub Pages. Правила, устройство кода и принятые решения — в [AGENTS.md](../AGENTS.md).
