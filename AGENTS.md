# AGENTS.md — как устроен и как разрабатывается репозиторий

Общая инструкция **и для людей, и для ИИ-агентов** (Claude Code, Codex, Cursor и др.): правила веток и коммитов,
устройство кода, договорённости по дизайну и решения, которые уже приняты, — с причинами. Перед тем как менять
код, прочитай раздел про ту часть, которую трогаешь. Поменял устройство — допиши сюда. `CLAUDE.md` — только
ссылка на этот файл для Claude Code. Что умеет сайт для пользователя — в [README.md](README.md).

Сайт группы М3102 (ИТМО, 1 курс) на React + TypeScript + Vite. Репозиторий — форк
[RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102): контент группы (конспекты, материалы,
дедлайны, ДЗ) лежит здесь же, в тех же папках и форматах.

## Правила, которые нельзя нарушать

| Правило | Подробности |
|---|---|
| **Коммиты — только от имени владельца** | `git -c user.name="LazerProOk1" commit …` (email из git-конфига). Никаких `Co-Authored-By` и упоминаний ИИ в коммитах, PR и описаниях. |
| **Чужой репозиторий не трогать** | В `RedstoneLord/itmo-m3102` ничего не пушить и PR не открывать без прямой просьбы владельца. |
| **Секреты — никогда в файлы** | Токены GitHub (PAT) не писать в файлы, коммиты, `.env`, логи и память. PAT пользователя живёт только в браузере (sessionStorage/localStorage, `src/services/github.ts`). |
| **Пароли ИТМО — никогда** | Сайт не принимает пароли студентов ни в каком виде (см. `docs/BACKEND_PLAN.md`). |
| **Контент группы — их формат** | `Конспекты/`, `Материалы/`, `Лабораторные/`, `Записи лекций/`, `Дедлайны/`, `data/`, `img/`, `tools/`, `.github/workflows/lectures-index.yml`, `normalize-names.yml` — данные и автоматизация группы. Формат не менять: их сайт читает их же. |
| **`legacy` руками не коммитить** | Это точная копия старого сайта группы, обновляется только синхронизацией. |

## Ветки и режимы

| Ветка | `.env` | Что это |
|---|---|---|
| `react-app` | `VITE_EDITING=false` | Основная. Только просмотр. Деплоится на GitHub Pages. |
| `react-app-dev` | `VITE_EDITING=true` | Плюс кнопка «Редактирование / Просмотр» в шапке: правка расписания, конспектов, ДЗ (с публикацией в GitHub), мемов, ссылок, сроков. |
| `design-aurora` | как `react-app` | Эксперимент с ярким оформлением. Не деплоится; в `react-app` вливать только по решению владельца. |
| `legacy` | — | Копия `master` из RedstoneLord (их старый статический сайт). |

**Как переносить код.** `react-app` и `react-app-dev` отличаются **только** `.env`. Код пишется в `react-app`, затем:

```bash
git checkout react-app-dev && git -c user.name="LazerProOk1" merge --no-edit react-app
git checkout design-aurora && git -c user.name="LazerProOk1" merge --no-edit react-app
git checkout react-app && git push origin react-app react-app-dev design-aurora
```

`VITE_EDITING=true` в dev сохраняется сам. В обратную сторону dev в `react-app` не мержить — приедет `.env`
с редактированием. Переключение веток ломает запущенный dev-сервер (HMR) — перезапусти его.

**Режим редактирования.** Флаг — `EDITING_ENABLED` в `src/features/settings/EditModeContext.tsx`. Всё, что меняет
общие данные, — за `const { isEditMode } = useEditMode()`. Личное (учебный план, «сделано», очередь на сдачу)
доступно в обеих ветках.

**Синхронизация `legacy`.** Actions → «Синхронизировать legacy с RedstoneLord» → Run workflow (и сама раз в сутки)
или «Sync fork» на ветке `legacy`. Встроенную «Sync fork» **не нажимать на `react-app` / `react-app-dev`**: она
предложит влить туда старый сайт или выбросить наши коммиты. Если RedstoneLord меняет `.github/workflows/`,
workflow падает с `refusing to allow a GitHub App to create or update workflow` — тогда «Sync fork» на `legacy`
или `gh api -X POST repos/LazerProOk1/itmo-m3102/merge-upstream -f branch=legacy` (токен со scope `workflow`).

**Что поменялось у группы:** `gh api "repos/RedstoneLord/itmo-m3102/commits?per_page=10"`. Контент сайт
подтягивает сам; в код переносить только изменения форматов и поведения (пример: метку `queue-signup` теперь
ставит их workflow, а не `?labels=` в ссылке).

## Команды, тесты и CI

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite; `.env` читается при старте — после смены перезапустить |
| `npm test` | Vitest, юнит-тесты `*.test.ts(x)` рядом с кодом |
| `npm run test:e2e` | Playwright: собирает сайт и гоняет сценарии в браузере (`e2e/`) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run build` | типы + сборка в `dist/` |
| `npm run size` | бюджет размера сборки (после `build`): `scripts/check-size.mjs` |
| `npm run lighthouse` | Lighthouse по `dist/` (`lighthouserc.json`); на Windows — `CHROME_PATH=путь к msedge.exe` |
| `npm run ics` | календарь-подписка `dist/m3102.ics` из данных группы (`scripts/build-ics.ts` через `tsx`, после `build`) |
| `npm run format` · `format:check` | Prettier (`.prettierrc.json`: одинарные кавычки, строка до 150) |

**CI** (`.github/workflows/deploy-pages.yml`, пуш в `react-app` и раз в сутки в 05:00 МСК — ради свежего `.ics`):
Prettier → юнит-тесты → сборка → календарь `m3102.ics` → бюджет размера → тесты в браузере → Lighthouse →
GitHub Pages. Упало — публикации нет; трассы упавших e2e — артефакт `e2e-traces`,
отчёт Lighthouse — артефакт `lighthouse`. Сайт: https://lazerprook1.github.io/itmo-m3102/ (`base: './'` + `HashRouter`
`#/schedule` — работает из подпапки без 404). Пуш в `.github/workflows/` требует у токена право `workflow`.

- **Бюджеты.** `npm run size` падает, если JS первой загрузки (~194 КБ gzip), CSS или одна страница (конспект
  ~198 КБ) тяжелее порога — так тяжёлая библиотека не попадёт в общий код незаметно. Lighthouse (3 прогона, медиана):
  доступность и практики ≥ 0,9 и CLS ≤ 0,1 — ошибка; производительность ≥ 0,5 — предупреждение (эмуляция слабого
  телефона шумит, сейчас ~0,55).
- **Тесты в браузере** (`e2e/`, `playwright.config.ts`) — по собранному сайту через `vite preview`, как на Pages
  (сервис-воркер, чанки, View Transitions). GitHub подменён заглушками `e2e/github.ts` (два конспекта: md и PDF,
  PDF генерируется в коде), остальной интернет обрывается. Часы — 1 октября 2026, 12:00 МСК. Сценарии: переход
  с главной на предмет (замер внутри страницы, < 1 с), поиск по тексту конспекта, неделя расписания, PDF,
  офлайн, телефон (свайп, нет горизонтальной прокрутки; проект `phone`, тег `@phone`). Локально — Edge
  (`channel: 'msedge'`), в CI — Chromium. Ждать синхронизацию — `openSynced()`. Упал — `npx playwright show-trace test-results/…/trace.zip`.
- **Юнит-тесты интерфейса** — `*.test.tsx` с `// @vitest-environment jsdom` (Testing Library); заглушки jsdom
  и отключённая сеть — `src/test/setup.ts`. Нетривиальная логика (парсеры, сортировки, слияния, раскладки) —
  с маленьким тестом рядом.
- **TypeScript строгий:** `strict`, `noUncheckedIndexedAccess`, `noImplicitReturns`. ESLint пока нет:
  `typescript-eslint` поддерживает TS только до 6.0, у нас 7 — подключить, когда выйдет поддержка.
- Код игры (`features/game/hedgehogGame.*`) Prettier не трогает (`.prettierignore`).

## Откуда берутся данные

Бэкенда нет. Всё хранится в `localStorage` браузера (zustand `persist`, ключи `m3102:*`, `src/lib/storage.ts`)
и подтягивается синхронизацией `syncGithubContent()` в `src/services/githubContent.ts`:

| Источник | Что берём |
|---|---|
| **RedstoneLord/itmo-m3102** (`REPOS.group`) | дерево файлов (1 запрос к API), `Конспекты/{Полное_имя_предмета}/{Лекция_N\|Практика_N\|Доп_Материалы}/файл`, `Дедлайны/deadlines.json`, `data/homework.json`, `data/links.json`, `data/schedule.json`; файлы — с raw.githubusercontent.com (без лимита) |
| **Kefirleos/itmo-vault** (`REPOS.stream`) | `Конспекты/1 семестр/Поток 1/{Предмет}/{NN}. {Тип} - {Название} ({дата}).md` и описания курсов |
| **GitHub Issues** группы | очередь на сдачу (`queue-signup`) |
| `src/data/m3102.ts` | то, чего нет у группы: предметы, студенты (с GitHub), сопоставление папок с предметами, запасное расписание до первой синхронизации |
| `src/data/greetings.ts` | приветствия главной (как `js/greetings.js` у RedstoneLord) |

Публикация в репозиторий группы (ДЗ, мемы) — `src/services/github.ts` (Contents API + PAT пользователя).
Записи из GitHub имеют id `gh:{путь}`; пропавшие из репозитория конспекты архивируются.

## Стиль кода

- Минимализм: без лишних абстракций и зависимостей; сначала поищи готовый компонент или утилиту.
- Комментарии по-русски, короткие, только «почему», а не «что». Тексты интерфейса — по-русски.
- Анимации — framer-motion (`lib/motion.ts`: `SPRING_SNAPPY`, `SPRING_SMOOTH`) и CSS. «Уменьшить движение»:
  CSS гасит общее правило в `global.css`, framer-motion — `<MotionConfig reducedMotion="user">` в `main.tsx`.
- Нетривиальная логика — с маленьким тестом рядом (`*.test.ts`).

## Решения по темам

### Синхронизация и данные

- **Кеш по sha:** у конспекта `sourceVersion` = `{PARSER_VERSION}:{sha из дерева}`, неизменённый файл не качается.
  Версия ставится, только если git blob sha скачанного совпал (raw кеширует ~5 мин). **Поменял разбор файлов
  (stripFrontMatter, splitTitle, quizPageToMarkdown, папки предметов) — увеличь `PARSER_VERSION`**, иначе старые
  конспекты останутся разобранными по-старому. Обрезанное дерево (`truncated`) — ошибка, а не архивация.
- **Статус** — `services/syncStore.ts` (кнопка в шапке, «Настройки», «Конспекты»). При открытии сайта — сама, не чаще
  раза в 10 минут (лимит API — 60/час без токена). Защита от двойного запуска — статус ставится до первого await.
  Нет сети → понятный текст и досинхронизация по `online`; лимит → `githubError()` пишет время сброса из `X-RateLimit-Reset`.
- **Хранилище:** личное — через `localStore` (`lib/storage.ts`): при нехватке места выбрасывается кеш конспектов
  и описаний курсов (скачаются заново) и запись повторяется; не помогло — предупреждение. Конспекты (~1 МБ) пишутся
  в простое (`idleStorage`). Битый JSON — пустое хранилище, а не падение.
- **Расписание** — из `data/schedule.json` группы (`services/groupSchedule.ts`), до первой синхронизации — из `m3102.ts`.
- **Очередь на сдачу** — issues `[id-дедлайна] текст` с меткой `queue-signup`. Кто стоит — `features/deadlines/queueNames.ts`:
  фамилия студента в тексте (записали друга) → он, иначе GitHub-автор по `M3102_STUDENTS`, «Имя Фамилия». Текст
  заголовка — мелкой припиской, только если в нём что-то сверх имени (уменьшительные — `DIMINUTIVES`).
  Новый студент в группе — добавь его GitHub. Сама страница обновляет очередь не чаще раза в 2 минуты.
- **API ИТМО** (my.itmo, БАРС, ITMO.ID) закрыты входом через ITMO ID и CORS — со статического сайта недоступны.
  План сервера (Go, ITMO ID, роли, мемы, очереди) — `docs/BACKEND_PLAN.md`.

### Конспекты, читалка, тесты

- **Совместимость с сайтом группы** (`components/markdown/Markdown.tsx` перед разбором): `:::тип … :::` → выноски,
  `$$x$$` одной строкой → формула по центру, `|` в формулах внутри таблиц → `\vert` (`lib/mathCompat.ts`).
  `\[ … \]` в формулы НЕ превращать: в конспектах это `\\[4pt]` внутри LaTeX.
- **Порядок занятий** как у группы: по номеру (Лекция 1, Практика 1, Лекция 2…) — `compareLessons`.
- **Папки** (`LectureNotesTab.tsx`): при сортировке «по номеру» конспекты предмета разложены по папкам занятий, как
  у группы (`?f=` — открытая папка, «Назад» — папка → предмет). Строки списков высокие (`.bigList`, 60px), нажимается
  вся строка (растянутая `::after` у ссылки, меню «⋯» — поверх неё): по тачпаду и пальцем легко попасть.
- **Чтение без фона:** открытый конспект ставит `<html data-reading>`, сияние `.aurora` гаснет (`aurora.css`).
- **Печать** (`@media print` в `global.css`, `AppShell`, `LectureNoteViewPage`): каркас — `display: block` (иначе
  сетка ставит статью в колонку меню 224px), `overflow: visible` у всего, кроме KaTeX (корни держатся на обрезке),
  код с переносом, тесты скрыты; номер страницы — `@page`. PDF-конспект печатается из своего файла
  (кнопка «Открыть PDF для печати») — постраничные холсты браузер режет. Проверять — `page.pdf()` в Playwright.
- **Маршрут** `materials/notes/*`, а не `:noteId`: id конспектов содержат `/`.
- **Скорость:** конспект рисуется по разделам `## ` (`lib/splitSections.ts`, `ProgressiveMarkdown`), сначала шапка и
  скелет. `Markdown` обёрнут в `memo` — иначе оглавление при прокрутке переразбирало конспект с KaTeX.
- **PDF** (`features/materials/PdfViewer.tsx`): холсты страниц создаются вручную в контейнере без React-детей
  и рисуются по одной очередью. Не переводить на `<Page>` из react-pdf — перерисовка React очищает холст.
  Тёмные страницы — `filter: invert(...) hue-rotate(180deg)`; страница «Продолжить» — `m3102:pdf-pages`.
- **Закладки и пометки** — `features/materials/marksStore.ts`; подсветка — CSS Custom Highlight API
  (`NoteMarks.tsx`, место — `lib/textRange.ts`), DOM конспекта не трогаем.
- **Тесты в конспектах:** блок ```quiz или файл-тест (`mode: quiz` первой строкой) — формат сайта группы
  (`parseQuiz.ts`). Файл-тест при синхронизации превращается в один блок ```quiz (`quizPageToMarkdown`).
- **Наши тесты «Проверь себя»** — `src/data/siteQuizzes/<путь как в Конспекты/>.md`, подключение —
  `features/materials/siteQuizzes.ts`. Показываются, только если в конспекте нет своего ```quiz. Вопросы только
  по предмету — без организационных (баллы, экзамены, правила). Новый конспект у группы — добавь тест сюда.
- **Результаты и повторение** — `features/quizzes/quizStore.ts` (ключ `site:<путь>` или `note:<путь>#<название>`,
  ошибка возвращается через 1–3–7–14 дней). Набор тестов предмета — `quizSources.ts`; смешанный тест — `CombinedQuiz.tsx`;
  прогресс предмета — `QuizProgress.tsx` (засчитан от 80%).
- **«Для ИИ»** на странице предмета (`subjects/aiDigest.ts`, `AiDigestButton`): всё по предмету одним .md —
  описание курса, оглавление, конспекты группы и потока по порядку занятий, текст PDF из `data/search-index.json`,
  материалы, свои заметки. PDF занятия, у которого есть .md, — ссылкой «PDF-версия» (дубль). Заголовки конспектов
  сдвинуты на 2 уровня, ссылки — с кириллицей (`readableUrls`): меньше токенов. Оценка — символы / 3.
- **Схемы** DSL группы (`plot`, `graph`, `diagram`, `tree`, `array`, `chart`, `canvas`) рисует свой рендерер
  (`components/diagrams`, синтаксис — README RedstoneLord). У графа `{color: …}`, `{dashed}`, петли, `layout: force`.
  **Код в `array` после `code:`** выполняет интерпретатор группы `arrayCode.js` — перенесён как есть, без eval
  (разбор в дерево, у кода нет доступа к window и localStorage); не править, при обновлении у группы — скопировать
  заново. Шаги показывает `ArrayPlayer.tsx` (фишки ячеек по id переезжают при обмене); для SVG/PNG и печати рядом
  скрытый кадр `print:` (`data-export-frame`).
- **Редактор схем** (`#/diagrams`, `features/diagrams/DiagramEditorPage.tsx`): источник истины — текст; мышь
  (перетаскивание, «Добавить», «Соединить», «Удалить», инспектор) правит его чистыми функциями
  `diagramEdits.ts` (с тестом), позиции пишутся как `@ x,y`. Отмена — стек текстов (набор склеивается за 700 мс).
  Ctrl+колесо — нативный слушатель с `passive: false` (у React `onWheel` пассивный). Ссылка «Поделиться» —
  `?lang=&src=` (base64url).

### Расписание и календарь

- **Неделя на ПК** — сетка по часам (`WeekView`, раскладка в `weekGrid.ts` с тестом): высота карточки = длительность
  (`--ppm` пикселей на минуту), пары в одно время делят колонку (дорожки), линия «сейчас», у прошедших тише
  содержимое. Воскресенье — только если есть пары. В узком окне планшета сетка листается вбок со snap.
- **Карточка пары** (`WeekOccurrenceCard`) — цветная плашка: оттенок типа пары и полоска слева; тип — словом.
  Нажимает невидимая кнопка на всю карточку, меню «⋯» — поверх неё (не кнопка в кнопке). Перенос с дефисом —
  только в узкой колонке (container query), название до 3 строк, «Лабораторная» → «Лаба».
- **Телефон** (< 768px): «Неделя» — список по дням (`WeekAgenda`, строки как в «Дне»); «День» — свайп
  влево/вправо меняет день, за край — соседняя неделя.
- **Календарь** (`calendar/calendarEntries.ts`) собирает пары, личные задачи, события, дедлайны группы (весь день,
  срок подписью, по местному времени) и ДЗ (в день `due`). Сделанное не показывается; дедлайн и ДЗ ведут на свои
  страницы. Месяц на телефоне — цветные полоски, нажатие на клетку открывает день.
- **Google / Apple Календарь** (`schedule/calendarExport.ts`, `lib/ics.ts` с тестом, окно `CalendarSyncDialog`):
  подписка на `m3102.ics` с сайта — общая для группы (пары, дедлайны, ДЗ); собирает `scripts/build-ics.ts` тем же
  кодом, что сайт. «Скачать .ics» — снимок плюс личное из браузера. Время — UTC из МСК (+3, без переходов), UID
  стабильные (иначе календарь задвоит события), отменённая пара — `STATUS:CANCELLED`, строки режутся по 75 байт.

### Главная

- Блоки — `today/homeLayout.ts` (список, порядок, широкие); порядок, скрытые, плотность и стартовая страница —
  в `settingsStore` (`homeOrder`, `homeHidden`, `density`, `startPage`), окно «Настроить главную». Новый блок —
  добавь в `HOME_BLOCKS`: у кого он не сохранён в порядке, встанет на своё место (`arrangeBlocks`).
- Плотность «Компактно» — `<html data-density="compact">`, уменьшает только шкалу `--space-4…16`; мелкие отступы
  и размеры шрифта не трогает.
- `/` открывает `startPage` (`StartPage` в `App.tsx`); «Главная» в меню всегда ведёт на `/today`.

### Дизайн и движение

- **Шрифты:** Unbounded (`--font-display`) — только главный заголовок страницы, крупные числа и название следующей
  пары; всё остальное — Inter. За каждым — `Inter Fallback` / `Unbounded Fallback` (`tokens.css`): Arial
  с подогнанными `size-adjust` и `ascent/descent-override`, чтобы подмена шрифта не сдвигала вёрстку (CLS).
  Меняешь шрифт — перемерь метрики (ширина текста и `fontBoundingBoxAscent/Descent` против Arial в canvas).
- **Цвет:** серые подкрашены акцентом, свечение — оттенки одного акцента. Радужные градиенты и градиентный текст
  выглядят «сгенерированно».
- **Движение:** `.stagger` — тихий каскад (4px, шаг 30 мс, не дольше 6 карточек); смена страницы и `Swap` — tween
  ~250 мс expo-out, без blur и пружин на больших областях. Модалка — чуть снизу без перехлёста; пустые состояния
  проявляются один раз, без бесконечного покачивания. Бесконечные анимации — только ёжик, фон и индикаторы загрузки.
- **Клик-эффекты** (`lib/ripple.ts`, включаются «Свечением»): волна — `<i class="ripple">` в конце кнопки/ссылки/карточки,
  поэтому внутри кнопок не опираться на `:last-child` (брать `span:last-of-type`). Рамка за курсором — `::after`
  у `[data-spot]`; карточке со своим `::after` — `data-spot="own"`. Кнопки получают `position: relative` (`:where`,
  слабее модулей) — у растянутой на строку кнопки (`::after` с `inset: 0`) ставь `position: static`, иначе нажимается
  только текст. Волна меряет свой слой, поэтому у такой кнопки идёт по всей строке.
- **Награда за «сделано»** (`lib/celebrate.ts`): `<Checkbox celebrate>` — искры; `useConfettiWhenCleared(open)` —
  конфетти и событие `m3102:cleared`, на которое из угла выглядывает ёжик с репликой (`CelebrateHedgehog` в
  `AppShell`, ~2,5 с, мимо него можно кликать). Только за вехи, не за каждую отметку.

### Единый визуальный язык

Новое сначала собирай из того, что есть в `#/design`; не хватает — добавь туда же общим компонентом.

| Что | Правило |
|---|---|
| **Отступы** | Только токены `--space-*` (сетка 4px). Внутри карточки — 12–16, между карточками — 16–24, между разделами страницы — 32–48. Плотность главной уменьшает шкалу от `--space-4`, поэтому отступы «на глаз» в px ломают компактный режим. |
| **Карточки** | `--radius-lg`, рамка `--color-border`, в покое тень не больше `--shadow-xs` (глубокие — только у всплывающего: меню, модалка). Одна карточка — одно действие: нажимается вся, вторичное — меню «⋯» поверх, кнопка в кнопке запрещена. |
| **Иконки** | lucide-react, `strokeWidth` 2: 16 в кнопках и строках, 14 в мелких кнопках и подписях, 18 в пустых состояниях. Иконка без подписи — с `aria-label` или `title`. |
| **Цвета** | Один акцент + статусы (`--color-success/warning/danger`). Цвет в расписании и календаре — **тип занятия** (`--color-lecture`, `--color-practice`, лаба, семинар), а не предмет: свой оттенок у каждого из шести предметов поверх четырёх типов уже не различить. Предмет — словом. |
| **Движение** | Появление — tween ~250 мс expo-out, каскад не длиннее 6 элементов; пружина — только у маленьких переключателей. Бесконечное — ёжик, фон, загрузка. Всё уважает «уменьшить движение». |
| **Телефон** | < 768px: цели нажатия от 44px, нижнее меню, без горизонтальной прокрутки страницы (проверяет e2e `@phone`), всплывающее — снизу и не закрывает нижнее меню. |

**Ёжик — маскот, а не украшение.** Где он есть: шапка главной — бегает по дорожке под приветствием, как
`.hero-hedgehog` на сайте группы (`HedgehogLane.tsx`: сценарий framer-motion — разгон и торможение по ширине дорожки,
у края присел, сальто, приземление с пружинкой, разворот; по клику сальто с репликой); пустые состояния (`EmptyState`, неподвижный), закрыт весь список (`CelebrateHedgehog`), индикатор
синхронизации, игра. Сезонная деталь (`season.ts` с тестом) — сама по дате, несколько дней в году: шапка Деда
Мороза, тыква, шапочка 1 сентября. Не добавлять: других постоянно скачущих ёжиков, всплывающие окна с ним,
ёжика рядом с ошибками и в читалке конспекта.

- **Переход «карточка → страница»** (`lib/morph.ts`, только мышь): ссылка `data-morph`, внутри `[data-morph-title]`,
  цель — h1 с `data-morph-target`. Внутри View Transition ждать таймерами — `requestAnimationFrame` там не срабатывает.
- **Живой фон** (`liveBg`): `appearance.ts` пишет `--bg-x/--bg-y/--bg-s` на `.aurora`.
- **Радио** в покое тихое: без тени, на телефоне — только кнопка воспроизведения.
- **Нижнее меню на телефоне:** в разделе вне вкладок на месте «Ещё» — его иконка и название.
- **Логотип в шапке** — `src/assets/logo-mask.webp` (600px, 6 КБ), уменьшенная копия `img/logo-t.png`.
- **Поле даты** — `components/ui/DateInput.tsx`, не `<input type="date">`.

### Скорость и загрузка

- Страницы — отдельные куски (`page()` в `App.tsx`), докачиваются в простое и с первого движения мыши/касания.
  Редкие и тяжёлые (дизайн-система, редактор схем) — `page(..., false)`, только по переходу.
- Markdown + KaTeX (~600 КБ) — только там, где нужен: на главной, в описании курса, в форме конспекта и в файлах
  группы — `LazyMarkdown` / `lazy()`. Рисовальщик схем — `lazy` при первой схеме; языки схем — `diagrams/languages.ts`.
  Не импортировать из тяжёлых страниц в лёгкие (так однажды вся страница предмета весила 672 КБ вместо 71).
- Поиск (`features/search/searchIndex.ts`) строит индекс один раз и пересобирает при смене данных.
- Ошибки — `components/ui/ErrorBoundary.tsx` вокруг каждой страницы (сбрасывается сменой пути) и всего приложения.
  Устаревший чанк после деплоя — сама перезагрузка, не чаще раза в 30 с.

### Офлайн и иконки

- `public/sw.js` + `public/manifest.webmanifest`. SW регистрируется только в сборке; при установке кладёт в кеш
  оболочку и все страницы по `asset-manifest.json` (без pdf.js и mermaid). Проверять — `vite preview`, не dev-сервером.
- Иконки — из логотипа группы `scripts/icon/source.jpg`: `node scripts/icon/make-icons.mjs` пишет `favicon.png`
  (только ёжик), `icon-192/512.png`, `apple-touch-icon.png`, `icon-maskable-512.png` (безопасная зона 80%).
  **Сменил файлы с постоянными именами (иконки) — подними `CACHE` в `sw.js`**, иначе у открывавших сайт останутся старые.

### Доступность и навигация

- Клавиатура: группы (SegmentedControl, Tabs, вкладки читалки, дни) — стрелки/Home/End через `lib/rovingKeys.ts`,
  Tab заходит только на выбранный вариант; первая остановка Tab — «Перейти к содержимому».
- Состояние разделов — в адресе (`/materials?tab=…&c=group&s=aisd`, `/subjects/:id?tab=…`), чтобы «Назад» шёл
  на шаг. Прокрутку при «Назад» восстанавливает `lib/useScrollMemory.ts`; на страницах не вызывать `scrollTo(0)`.
- Горячие клавиши — `features/help/ShortcutsDialog.tsx` (`?`); новая клавиша — добавь туда же.

## Подводные камни

- На Windows не править TS/регулярки через Python- или bash-heredoc — портятся `\n`, `\d` и обратные слеши.
  Файлы в репозитории бывают с CRLF: заменяя текст скриптом, учитывай `\r\n`.
- Vite кеширует модули: странные ошибки после правки или смены ветки — перезапусти dev-сервер.
- Лимит GitHub API — 60 запросов в час на сеть: снимки страниц и Lighthouse по живому сайту быстро его съедают.
  Для проверок подставляй дерево файлов (`gh api …/git/trees/…`), как в `e2e/github.ts`.
- Игра «Ёжик-кувырок» (`features/game/hedgehogGame.js`) — код RedstoneLord, перенесён как есть; наши правки
  помечены «Правка поверх оригинала». При обновлении его игры — перенести заново и повторить правки.
- `lib/download.ts` — `saveBlob` / `downloadUrl`: атрибут `download` у ссылок на другой домен браузер игнорирует,
  поэтому чужие файлы качаются через fetch.
