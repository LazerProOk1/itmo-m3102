title: Проверь себя: отображения, Пеано, индукция, мощность
description: Инъекции, сюръекции и биекции, композиция и обратимость, аксиомы Пеано, индукция и вполне упорядоченность, равномощность и счётные множества.

? Как правильно записать инъективность $f: A \to B$?
- [x] $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$ :: Из равенства образов следует равенство прообразов.
- [ ] $x_1 = x_2 \Rightarrow f(x_1) = f(x_2)$ :: Это верно для любой функции и ничего не проверяет.
- [ ] $\forall y \in B\ \exists x: f(x) = y$ :: Это сюръективность.

? Является ли $f(x) = x^2$ сюръекцией?
- [x] Зависит от области прибытия: $\mathbb{R} \to [0; +\infty)$ — да, $\mathbb{R} \to \mathbb{R}$ — нет :: Сюръективность зависит от выбора $B$.
- [ ] Всегда да :: Отрицательные числа не достигаются в $\mathbb{R}$.
- [ ] Всегда нет :: На $[0; +\infty)$ достигается каждое значение.

? В записи $g \circ f$ какое отображение применяется первым?
- [x] $f$ :: $(g \circ f)(x) = g(f(x))$.
- [ ] $g$ :: Порядок применения обратен порядку записи.

? Когда у $f: X \to Y$ есть обратное отображение?
- [x] Тогда и только тогда, когда $f$ — биекция :: Сюръективность даёт $g(y)$ для каждого $y$, инъективность — его единственность.
- [ ] Когда $f$ инъективна :: Без сюръективности $g$ не определено на всём $Y$.
- [ ] Всегда, если $X = Y$ :: Например, $f(x) = 0$ на $\mathbb{R}$ необратима.

? Какая аксиома Пеано говорит, что у единицы нет предшественника?
- [x] $\forall n: \sigma(n) \ne 1$ :: Отображение следования несюръективно.
- [ ] $\sigma$ инъективно :: Это про разных последователей у разных чисел.
- [ ] Аксиома индукции :: Она запрещает «лишние» элементы в $\mathbb{N}$.

? Принцип математической индукции в лекции — это...
- [x] Следствие аксиомы индукции (пятой аксиомы Пеано) :: Множество $M$ всех $n$, где $P(n)$ истинно, содержит 1 и замкнуто относительно $\sigma$, значит $M = \mathbb{N}$.
- [ ] Отдельная аксиома, не связанная с Пеано :: Он выводится из аксиомы 5.
- [ ] Теорема, верная только для конечных множеств :: Индукция работает на всём $\mathbb{N}$.

? Почему $\mathbb{N} \sim 2\mathbb{N}$ (парадокс Дедекинда)?
- [x] $\varphi(n) = 2n$ — биекция $\mathbb{N}$ на чётные числа :: Бесконечное множество равномощно своей собственной части.
- [ ] Потому что чётных чисел ровно половина :: Для бесконечных множеств «половина» не уменьшает мощность.
- [ ] Это неверно: чётных меньше :: Биекция существует — значит, мощности равны.

? Что даёт теорема Кантора — Бернштейна?
- [x] Если есть инъекции $A \to B$ и $B \to A$, то $A \sim B$ :: Часто проще построить две инъекции, чем одну биекцию.
- [ ] Булеан множества мощнее самого множества :: Это другая теорема Кантора.
- [ ] Любые бесконечные множества равномощны :: $\mathbb{R}$ несчётно.

? Счётно ли объединение счётного числа счётных множеств?
- [x] Да — теорема Кантора :: Элементы можно занумеровать «по диагоналям».
- [ ] Нет, оно всегда несчётно :: Например, $\mathbb{Q}$ — счётное объединение счётных множеств и счётно.
- [ ] Только если множества не пересекаются :: Пересечения не мешают: дубли просто пропускаются.
