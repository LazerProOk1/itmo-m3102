title: Проверь себя: число $e$, Больцано — Вейерштрасс, критерий Коши
description: Неопределённость $1^\infty$, последовательность $(1 + \frac1n)^n$, подпоследовательности и частичные пределы, фундаментальные последовательности.

? Какая неопределённость в пределе $\lim (1 + \frac1n)^n$?
- [x] $1^\infty$ :: Основание стремится к 1, показатель — к бесконечности.
- [ ] $\frac00$ :: Это неопределённость первого замечательного предела.
- [ ] $\infty - \infty$ :: Здесь нет разности.

? Что доказывается про $x_n = (1 + \frac1n)^n$?
- [x] Она монотонно возрастает :: Сравнение слагаемых бинома Ньютона для $x_n$ и $x_{n+1}$.
- [x] Она ограничена сверху числом 3 :: Через оценку $\frac{1}{k!} \le \frac{1}{2^{k-1}}$.
- [ ] Она убывает к $e$ :: Она возрастает.
explain: Монотонная ограниченная последовательность сходится — её предел и называют числом $e$.

? Что утверждает теорема Больцано — Вейерштрасса?
- [x] Из любой ограниченной последовательности можно выбрать сходящуюся подпоследовательность :: Доказательство — делением отрезка пополам и принципом вложенных отрезков.
- [ ] Любая ограниченная последовательность сходится :: $(-1)^n$ — контрпример.
- [ ] Любая монотонная последовательность ограничена :: $x_n = n$ монотонна и не ограничена.

? Сколько частичных пределов у $x_n = \frac{1 + (-1)^n}{2}$? Введите число.
= 2
correct: Члены чередуются: $0, 1, 0, 1, \dots$ — частичные пределы 0 и 1.
wrong: При нечётных $n$ получается 0, при чётных — 1. Подпоследовательности сходятся к 0 и к 1 — два частичных предела.

? Какая последовательность называется фундаментальной?
- [x] $\forall \varepsilon > 0\ \exists N\ \forall n, m > N: |x_n - x_m| < \varepsilon$ :: Любые два далёких члена близки.
- [ ] $\forall \varepsilon > 0\ \exists N\ \forall n > N: |x_{n+1} - x_n| < \varepsilon$ :: Соседние члены — слабее: так ведут себя и частичные суммы $\sum \frac1k$, которые расходятся.
- [ ] Ограниченная и монотонная :: Это условие сходимости по Вейерштрассу, а не определение.

? Что утверждает критерий Коши?
- [x] Последовательность сходится тогда и только тогда, когда она фундаментальна :: Сходимость проверяется без знания предела.
- [ ] Фундаментальная последовательность монотонна :: Монотонность не нужна.
- [ ] Сходящаяся последовательность может быть не фундаментальной :: Необходимость доказана: сходящаяся всегда фундаментальна.

? Что такое подпоследовательность $\{x_{n_k}\}$?
- [x] Члены исходной последовательности с номерами $n_1 < n_2 < \dots$, взятые в том же порядке :: Номера строго возрастают.
- [ ] Любой набор членов в любом порядке :: Порядок номеров сохраняется.
- [ ] Первые $k$ членов последовательности :: Подпоследовательность бесконечна.
