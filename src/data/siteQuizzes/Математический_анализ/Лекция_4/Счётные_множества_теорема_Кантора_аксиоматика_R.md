title: Проверь себя: счётность, теорема Кантора, аксиомы $\mathbb{R}$
description: Счётность $\mathbb{Z}$ и $\mathbb{Q}$, теорема Кантора о булеане, аксиомы поля и порядка, аксиома Дедекинда, плотность и непрерывность, принцип Архимеда.

? Какие множества счётны?
- [x] $\mathbb{Z}$ :: Нумеруем по очереди: $0, -1, 1, -2, 2, \dots$
- [x] $\mathbb{Q}$ :: Несократимые дроби $p/q$ вкладываются в счётное $\mathbb{Z} \times \mathbb{N}$.
- [ ] $\mathbb{R}$ :: $\mathbb{R}$ несчётно.
- [x] $2\mathbb{N}$ :: Биекция $n \mapsto 2n$.

? Зачем при нумерации $\mathbb{Q}$ требуют несократимую запись $p/q$?
- [x] Чтобы у каждого рационального числа была ровно одна запись и отображение было корректно определено :: Иначе $\frac12$ и $\frac24$ считались бы разными.
- [ ] Чтобы дроби были меньше 1 :: Несократимость не ограничивает величину.
- [ ] Чтобы исключить отрицательные числа :: Знак хранится в $p \in \mathbb{Z}$.

? Что утверждает теорема Кантора?
- [x] $|A| < |\mathcal{P}(A)|$ для любого множества $A$ :: Инъекция $a \mapsto \{a\}$ есть, а сюръекции нет.
- [ ] $|A| = |\mathcal{P}(A)|$ для бесконечных $A$ :: Именно это теорема опровергает.
- [ ] Счётное объединение счётных множеств счётно :: Это другая теорема Кантора.
explain: Сюръекции нет из-за «диагонального» множества $B = \{a \in A : a \notin g(a)\}$ — оно не может быть ничьим образом.

? Какие аксиомы порядка входят в определение упорядоченного поля?
- [x] Линейность: любые два элемента сравнимы :: $(a \le b) \vee (b \le a)$.
- [x] $a \le b \Rightarrow a + c \le b + c$ :: Согласованность со сложением.
- [x] $a \ge 0,\ b \ge 0 \Rightarrow ab \ge 0$ :: Согласованность с умножением.
- [ ] $a \le b \Rightarrow ac \le bc$ для любого $c$ :: При $c < 0$ неравенство меняет знак.

? Что утверждает аксиома Дедекинда?
- [x] Если непустое $A$ левее непустого $B$, найдётся $c$: $a \le c \le b$ для всех $a \in A$, $b \in B$ :: На числовой прямой нет «дырок».
- [ ] Между любыми двумя числами есть третье :: Это плотность.
- [ ] $\mathbb{N}$ не ограничено сверху :: Это принцип Архимеда.

? Почему в $\mathbb{Q}$ аксиома Дедекинда не выполняется?
- [x] Для $A = \{x > 0 : x^2 < 2\}$ и $B = \{x > 0 : x^2 > 2\}$ разделяющий элемент должен удовлетворять $c^2 = 2$, а $\sqrt2 \notin \mathbb{Q}$ :: В $\mathbb{Q}$ на месте $\sqrt2$ «дырка».
- [ ] Потому что $\mathbb{Q}$ счётно :: Счётность здесь не аргумент.
- [ ] Потому что в $\mathbb{Q}$ нет порядка :: Порядок есть, $\mathbb{Q}$ — упорядоченное поле.

? $\mathbb{Q}$ плотно, но не непрерывно. Что это значит?
- [x] Между любыми двумя рациональными есть третье, но некоторые сечения не имеют разделяющей точки в $\mathbb{Q}$ :: Плотность и непрерывность — разные свойства.
- [ ] Это одно и то же :: $\mathbb{Q}$ показывает, что нет.
- [ ] В $\mathbb{Q}$ между соседними числами нет промежутков :: У рациональных чисел нет «соседей».

? Что утверждает принцип Архимеда?
- [x] $\mathbb{N}$ не ограничено в $\mathbb{R}$: для любого $x$ есть натуральное $n > x$ :: Доказывается от противного через аксиому Дедекинда.
- [ ] $\mathbb{R}$ счётно :: Нет.
- [ ] Любое число — предел рациональных :: Это о плотности $\mathbb{Q}$ в $\mathbb{R}$.
