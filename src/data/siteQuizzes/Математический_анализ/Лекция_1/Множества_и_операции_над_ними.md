title: Проверь себя: множества и отображения
description: Логическое «или», операции над множествами, законы Де Моргана для семейств, декартово произведение, отображения, образ и прообраз.

? Что значит $\vee$ («или») в математике?
- [x] Хотя бы одно из утверждений истинно, возможно оба :: Неисключающее «или».
- [ ] Ровно одно из двух, но не оба :: Это исключающее «или» (xor), как в бытовой речи.

? Что такое $A \mathbin{\triangle} B$?
- [x] Элементы, лежащие ровно в одном из множеств :: Объединение без пересечения.
- [ ] Элементы, лежащие в обоих множествах :: Это пересечение.
- [ ] Элементы $A$, которых нет в $B$ :: Это разность $A \setminus B$.

? Закон Де Моргана для семейства множеств:
- [x] $\overline{\bigcup_\alpha A_\alpha} = \bigcap_\alpha \overline{A_\alpha}$ :: «Не попал ни в одно» — то же, что «не попал в каждое».
- [ ] $\overline{\bigcup_\alpha A_\alpha} = \bigcup_\alpha \overline{A_\alpha}$ :: Объединение должно смениться пересечением.
- [ ] $\overline{\bigcap_\alpha A_\alpha} = \bigcap_\alpha \overline{A_\alpha}$ :: Пересечение должно смениться объединением.

? Какое равенство для декартова произведения верно?
- [x] $A \times (B \cap C) = (A \times B) \cap (A \times C)$ :: Произведение дистрибутивно относительно $\cap$ и $\cup$.
- [ ] $A \times B = B \times A$ всегда :: Пары упорядоченные: $(a, b) \ne (b, a)$ при $a \ne b$.
- [ ] $A \times \varnothing = A$ :: Пар со вторым элементом из пустого множества нет: $A \times \varnothing = \varnothing$.

? Что требуется от отображения $f: X \to Y$?
- [x] Каждому $x$ из области определения сопоставлен единственный $y \in Y$ :: Одному аргументу — одно значение.
- [ ] Каждому $y \in Y$ сопоставлен единственный $x$ :: Это условие биекции, а не функции.
- [ ] Разным $x$ соответствуют разные $y$ :: Это инъективность.

? Чем область значений $\mathrm{Im}(f)$ отличается от области прибытия $Y$?
- [x] $\mathrm{Im}(f)$ — значения, которые реально достигаются; $Y$ — куда они заявлены попадать :: Если $\mathrm{Im}(f) = Y$, функция сюръективна.
- [ ] Ничем :: Например, $x^2: \mathbb{R} \to \mathbb{R}$ не принимает отрицательных значений.
- [ ] $\mathrm{Im}(f)$ всегда больше $Y$ :: Образ — подмножество $Y$.

? $f(x) = x^2$ на $\mathbb{R}$. Сколько элементов в полном прообразе $f^{-1}(\{4\})$? Введите число.
= 2
correct: $f^{-1}(\{4\}) = \{-2, 2\}$.
wrong: Полный прообраз — все $x$, у которых $f(x) \in \{4\}$: $x^2 = 4$ при $x = -2$ и $x = 2$.

? Означает ли запись $f^{-1}(B)$, что у $f$ есть обратная функция?
- [ ] Да :: Это частая ловушка.
- [x] Нет: полный прообраз определён для любой функции :: Например, у $x^2$ на $\mathbb{R}$ обратной нет, а прообразы есть.
