title: Проверь себя: поиск «hello» при чтении файла порциями
description: Буферное чтение, конечный автомат с состоянием match_id, сохранение состояния между вызовами, fread и завершающий ноль.

? Почему нельзя искать `"hello"` в каждом прочитанном буфере независимо?
- [x] Слово может разорваться между двумя буферами: `"hel"` в одном, `"lo"` в другом :: Такие вхождения потеряются.
- [ ] Потому что `strstr` не работает с файлами :: Дело не в функции, а в границах буферов.
- [ ] Потому что буфер слишком большой :: Проблема есть при любом размере буфера.

? Что хранит `match_id`?
- [x] Сколько подряд символов слова `"hello"` уже совпало с последними прочитанными :: Это состояние автомата.
- [ ] Сколько раз слово уже найдено :: Это отдельный счётчик `match`.
- [ ] Номер текущего буфера :: Автомату это не нужно.

? Что должно происходить с `match_id` между буферами?
- [x] Сохраняться: функция получает его через указатель или контекст и записывает обратно :: Тогда автомат продолжает поиск с того же места.
- [ ] Обнуляться перед каждым буфером :: Тогда потеряются вхождения на границах.
- [ ] Увеличиваться на размер буфера :: Это не связано с числом совпавших символов.

? Автомат ждал `hello[3] = 'l'`, а пришёл символ `h`. Каким станет `match_id`? Введите число.
= 1
correct: Этот `h` сам может начинать новое слово, поэтому состояние — 1, а не 0.
wrong: Совпадение прервалось, но пришедший символ `h` совпадает с `hello[0]` — новое совпадение начинается с него, поэтому `match_id = 1`.

? Сколько вхождений `"hello"` найдёт автомат в строке `"helhellohello"`? Введите число.
= 2
correct: Первое `hel` обрывается, дальше два полных `hello`.
wrong: Разберите посимвольно: `hel` → сбой на `h` (состояние 1), затем `hello` (1-е вхождение), затем ещё `hello` (2-е).

? Что значит `static const char* hello = "hello";` внутри функции?
- [x] Инициализация выполняется один раз, при первом вызове функции :: Не пересоздаётся при каждом вызове.
- [ ] Переменная видна во всех файлах программы :: `static` внутри функции ограничивает время инициализации, а не видимость.
- [ ] Строку можно изменять :: `const char*` указывает на неизменяемые данные.

? Что возвращает `fread` в цикле `while ((cnt = fread(...)) > 0)`?
- [x] Сколько элементов реально прочитано — в конце файла может быть меньше `BUF_SIZE` :: Поэтому в подсчёт передают `cnt`, а не `BUF_SIZE`.
- [ ] Всегда `BUF_SIZE` :: Последний кусок обычно короче.
- [ ] Код ошибки :: Ошибку и конец файла проверяют отдельно (`ferror`, `feof`).

? Чем опасна строка `buf[cnt < BUF_SIZE ? cnt : BUF_SIZE - 1] = '\0';` при полностью заполненном буфере?
- [x] Она затирает последний реально прочитанный символ :: Для вывода нужен буфер на один байт больше.
- [ ] Она выходит за границу массива :: Индекс `BUF_SIZE - 1` в пределах массива.
- [ ] Ничем :: Последний символ куска теряется при выводе.
