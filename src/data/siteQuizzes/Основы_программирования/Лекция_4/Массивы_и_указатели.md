title: Проверь себя: массивы, указатели, C-строки
description: Устройство массива, array-to-pointer decay, sizeof в функции, арифметика указателей, указатель end, C-строки и сравнение строк.

? Что правда про встроенный массив C++?
- [x] Элементы одного типа лежат в памяти подряд :: Без промежутков.
- [x] Размер задаётся при создании и не меняется :: Для изменяемого размера есть `std::vector`.
- [x] Индексы от `0` до `N - 1` :: Индекс `N` — уже за границей.
- [ ] Элементы `int a[10];` инициализируются нулями :: Без инициализатора значения неопределены.

? Что происходит при array-to-pointer decay?
- [x] Массив `T[N]` неявно превращается в `T*` на первый элемент :: Это `&values[0]`.
- [ ] Массив копируется в новую память :: Элементы не копируются.
- [ ] Размер массива передаётся вместе с указателем :: Указатель хранит только адрес.

? Массив `int values[10]` передали в функцию `void f(int values[])`. Что вернёт `sizeof(values)` внутри функции на 64-битной системе? Введите число.
= 8
correct: Параметр — на самом деле `int*`, и `sizeof` возвращает размер указателя.
wrong: Параметр-массив в функции превращается в указатель `int*`, поэтому `sizeof` даёт размер указателя (8 байт), а не $10 \cdot 4 = 40$.

? `int* p` указывает на `a[2]`. Куда указывает `p + 1`?
- [x] На `a[3]` :: Смещение считается в элементах, а не в байтах.
- [ ] На байт после начала `a[2]` :: Компилятор сам умножает на `sizeof(int)`.
- [ ] На `a[1]` :: `+1` — вперёд.

? Указатель `end` на позицию сразу после последнего элемента. Что с ним можно делать?
- [x] Получать и сравнивать с другими указателями :: Так устроены циклы `for (p = begin; p != end; ++p)`.
- [ ] Разыменовывать `*end` :: Это чтение за границей массива — неопределённое поведение.
- [ ] Двигать дальше `end + 1` :: Выход дальше `end` тоже UB.

? Сколько ячеек `char` нужно, чтобы хранить C-строку `"C++"`? Введите число.
= 4
correct: Три символа плюс завершающий `'\0'`.
wrong: C-строка заканчивается нулевым символом `'\0'`, он не входит в длину, но занимает место: $3 + 1 = 4$.

? Что сравнивает `a == b` для двух `const char*`?
- [x] Адреса, а не содержимое строк :: Для содержимого — `strcmp` или посимвольное сравнение.
- [ ] Строки посимвольно :: Так работает `std::string`, но не указатели.
- [ ] Длины строк :: Длины не сравниваются.

? Что вернёт `strcmp("abc", "abd")`?
- [x] Отрицательное число :: Первая строка лексикографически раньше.
- [ ] 0 :: 0 — только для равных строк.
- [ ] Положительное число :: Положительное — если первая позже.

? Чем `char second[] = "Hello world";` отличается от строкового литерала?
- [x] Создаётся отдельный изменяемый массив-копия, литерал только инициализирует его :: Менять `second` можно.
- [ ] Ничем: `second` указывает на литерал :: Это было бы `const char* first = "...";`.
- [ ] Литерал копируется без `'\0'` :: Нулевой символ тоже копируется.
