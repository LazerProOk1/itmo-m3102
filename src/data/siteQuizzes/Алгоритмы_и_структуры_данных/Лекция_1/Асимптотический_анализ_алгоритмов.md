title: Проверь себя: асимптотический анализ
description: Алгоритм и трудоёмкость, нотации O, Ω, Θ, оценка циклов и сортировка вставками.

? Что означает $f(n) \in O(g(n))$?
- [ ] Для всех $n$ выполняется $f(n) \le g(n)$ :: Определение допускает константу $c$ и разрешает нарушения при малых $n$.
- [x] Существуют $c > 0$ и $n_0$, что при всех $n > n_0$ выполнено $0 \le f(n) \le c \cdot g(n)$ :: Это и есть оценка сверху с точностью до константы.
- [ ] Существуют $c_1, c_2$, что $c_2 g(n) \le f(n) \le c_1 g(n)$ :: Это определение $\Theta$, оно требует оценку и сверху, и снизу.
- [ ] $f(n)$ растёт строго медленнее $g(n)$ :: $O$ допускает и одинаковый рост: $n \in O(n)$.
explain: $O$ — оценка сверху: начиная с некоторого $n_0$, $f$ не превышает $g$, умноженную на константу.

? Для $f(n) = 3n + 5$ взяли $c = 4$. Начиная с какого $n$ выполняется $3n + 5 \le 4n$? Введите наименьшее целое $n$.
= 5
correct: $3n + 5 \le 4n \iff n \ge 5$.
wrong: Перенесите $3n$ вправо: $5 \le n$. Значит, неравенство верно при $n \ge 5$, и в определении можно взять $n_0 = 5$.

? Какие свойства выполняются для $\Theta$, но НЕ для $O$?
- [ ] Транзитивность :: Транзитивны все три обозначения.
- [ ] Рефлексивность :: $f \in O(f)$ тоже верно.
- [x] Симметрия: $f \in \Theta(g) \iff g \in \Theta(f)$ :: $O$ задаёт направленное отношение «не быстрее»: $n \in O(n^2)$, но $n^2 \notin O(n)$.
explain: Симметрия — особенность $\Theta$. Для $O$ и $\Omega$ есть двойственность: $f \in O(g) \iff g \in \Omega(f)$.

? Какая оценка у цикла `for (i = 0; i * i < n; ++i) {}`?
- [ ] $O(1)$ :: Число итераций растёт вместе с $n$.
- [x] $O(\sqrt{n})$ :: Цикл идёт, пока $i^2 < n$, то есть примерно $\sqrt{n}$ раз.
- [ ] $O(n)$ :: Счётчик проходит не до $n$, а до $\sqrt{n}$.
- [ ] $O(\log n)$ :: Логарифм получился бы, если бы $i$ удваивался.
explain: Это пример сублинейной, но не константной сложности.

? Внешний цикл делает 100 итераций, внутренний — $n$. Какая оценка?
- [ ] $O(n^2)$ :: Квадрат был бы, если бы оба цикла зависели от $n$.
- [x] $O(n)$ :: $100n$ — константа 100 отбрасывается.
- [ ] $O(100)$ :: От $n$ работа всё-таки зависит.
explain: Вложенность сама по себе не увеличивает порядок роста: растёт только множитель, зависящий от $n$.

? Какие утверждения про сортировку вставками верны?
- [x] В худшем случае (массив в обратном порядке) она работает за $\Theta(n^2)$ :: На шаге $i$ сдвигаются все $i$ элементов: $\frac{n^2 - n}{2}$ сдвигов.
- [x] На уже отсортированном массиве — за $O(n)$ :: Каждый элемент сразу остаётся на месте.
- [x] Она работает «на месте» и требует $O(1)$ дополнительной памяти :: Переставляет элементы внутри исходного массива.
- [ ] Ей нужен дополнительный массив размера $n$ :: Это про сортировку слиянием.
