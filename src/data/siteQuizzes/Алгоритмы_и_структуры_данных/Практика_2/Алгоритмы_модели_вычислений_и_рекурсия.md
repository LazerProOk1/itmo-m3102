title: Проверь себя: модели вычислений и рекурсия
description: Машина Тьюринга, RAM и word RAM, закон адресации, дерево рекурсии и мастер-теорема в форме с $c$ и $d$.

? Из чего состоит машина Тьюринга?
- [x] Бесконечная лента из ячеек с символами алфавита :: Это её память.
- [x] Головка, которая читает, пишет и сдвигается на одну ячейку :: Доступ только к соседним ячейкам.
- [x] Конечный набор состояний и таблица переходов :: Она и задаёт «программу».
- [ ] Произвольный доступ к ячейке по адресу :: Это свойство RAM, а не машины Тьюринга.

? Почему скорость алгоритмов оценивают в RAM, а не на машине Тьюринга?
- [ ] RAM вычисляет больше функций :: По вычислимости модели равны.
- [x] RAM ближе к реальному компьютеру: к ячейке обращаются по номеру за один шаг :: На ленте до нужной ячейки надо долго ехать головкой.
- [ ] На машине Тьюринга нельзя записать сортировку :: Можно, просто очень неэффективно.
explain: Утверждение о машине Тьюринга — о принципиальной вычислимости, а не об эффективности.

? Какое соглашение о «шаге» принято в word RAM?
- [x] Любая операция над двумя машинными словами — 1 такт :: Сложение, сравнение, чтение по адресу и т. п.
- [ ] Операция над числом из $k$ цифр — $k$ тактов :: Так считают «длинную» арифметику, а в word RAM числа помещаются в слово.
- [ ] Один такт — одна строка кода :: Строка может содержать много операций.
explain: Это верно, пока числа помещаются в слово фиксированной длины $w$.

? В дереве рекурсии что отвечает за время, а что за память?
- [x] Время — суммарная работа во всех узлах; память — глубина дерева :: Одновременно на стеке лежит только одна ветка вызовов.
- [ ] Время — глубина; память — число узлов :: Наоборот.
- [ ] И то и другое — число листьев :: Листья — только часть узлов.

? Сколько уровней в дереве рекурсии Merge Sort на массиве из $n$ элементов?
- [ ] $n$ :: Размер уменьшается не на 1, а вдвое.
- [x] Около $\log_2 n$ :: На уровне $k$ размер $n / 2^k$, база — при $n / 2^k = 1$.
- [ ] $\sqrt{n}$ :: Корень здесь ни при чём.
explain: Каждый уровень стоит $O(n)$, уровней $\log_2 n$ — итого $O(n \log n)$.

? $T(n) = 8T(n/2) + O(n^2)$. Чему равно $d = \log_b a$ и какой ответ?
- [x] $d = 3$, случай $c < d$: $T(n) = \Theta(n^3)$ :: $\log_2 8 = 3$, а $c = 2 < 3$.
- [ ] $d = 4$, $T(n) = \Theta(n^4)$ :: $\log_2 8 = 3$, а не $8/2$.
- [ ] $d = 2$, $T(n) = \Theta(n^2 \log n)$ :: Это был бы случай $c = d$.
explain: Размножение подзадач ($n^3$) растёт быстрее дополнительной работы ($n^2$) — оно и определяет ответ.

? Какие ошибки при применении мастер-теоремы названы в практике?
- [x] Сравнивать $a$ и $b$ напрямую вместо $c$ и $d = \log_b a$ :: Сравниваются именно показатели.
- [x] Считать $c$ по работе всей задачи, а не одного вызова :: $c$ — про нерекурсивную работу одного вызова.
- [x] Применять её к рекурсии с подзадачами разного размера :: Теорема в этом виде — только для $a$ подзадач размера $n/b$.
- [ ] Применять её к Merge Sort :: Для Merge Sort она как раз работает: случай $c = d$.
