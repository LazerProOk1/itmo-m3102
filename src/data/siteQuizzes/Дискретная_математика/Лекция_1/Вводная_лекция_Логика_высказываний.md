title: Проверь себя: логика высказываний
description: Высказывания и связки, импликация и вакуумная истинность, интерпретации, классы формул, следствие и теорема дедукции.

? Какие из этих предложений — высказывания?
- [x] «$2 + 2 = 5$» :: Ложное, но высказывание: у него есть истинностное значение.
- [x] «Москва — столица России» :: Истинное высказывание.
- [ ] «Закрой дверь!» :: Побуждение не бывает истинным или ложным.
- [ ] «Который час?» :: Вопрос — не высказывание.
explain: Высказывание — повествовательное утверждение, которое либо истинно, либо ложно.

? Когда импликация $P \to Q$ ложна?
- [x] Только когда $P$ истинно, а $Q$ ложно :: Во всех остальных трёх случаях она истинна.
- [ ] Когда $P$ ложно :: При ложной посылке импликация истинна — вакуумная истинность.
- [ ] Когда $P$ и $Q$ имеют разные значения :: Это условие ложности эквивалентности $P \leftrightarrow Q$.

? Истинно ли высказывание «Если $2 + 2 = 5$, то я — император»?
- [x] Да: посылка ложна, а из ложной посылки следует что угодно :: Это вакуумная истинность.
- [ ] Нет: я не император :: Заключение не важно, если посылка ложна.
- [ ] Не определено :: У импликации всегда есть значение.

? Чему равносильно отрицание импликации $\neg(A \to B)$?
- [x] $A \wedge \neg B$ :: Импликация ложна ровно тогда, когда $A$ истинно, а $B$ ложно.
- [ ] $\neg A \to \neg B$ :: Это обратное противоположное, оно не равносильно отрицанию.
- [ ] $\neg A \wedge B$ :: При $A = 0$ импликация истинна, её отрицание ложно.

? Сколько строк в таблице истинности формулы от 4 переменных? Введите число.
= 16
correct: Каждая переменная принимает 2 значения: $2^4 = 16$ интерпретаций.
wrong: Таблица перечисляет все интерпретации — функции $v: V \to \{0, 1\}$. Для 4 переменных их $2^4 = 16$.

? Какие утверждения о классах формул верны?
- [x] $A \vee \neg A$ — тавтология :: Истинна при любой интерпретации.
- [x] $A \wedge \neg A$ — противоречие :: Ложна при любой интерпретации.
- [x] Любая тавтология выполнима :: Она истинна хотя бы при одной интерпретации — при всех.
- [ ] Любая выполнимая формула — тавтология :: Выполнимая может быть ложной при других интерпретациях.

? Как в лекции раскрывается запись $\neg A \vee B \wedge C$?
- [x] $(\neg A) \vee (B \wedge C)$ :: Сначала отрицание, потом конъюнкция, затем дизъюнкция.
- [ ] $\neg(A \vee B) \wedge C$ :: Отрицание действует только на ближайшую переменную.
- [ ] $(\neg A \vee B) \wedge C$ :: Конъюнкция сильнее дизъюнкции.
explain: Лучше ставить скобки явно и не полагаться на память о приоритетах.

? Что утверждает теорема дедукции?
- [x] $A \models B$ тогда и только тогда, когда $\models A \to B$ :: Следствие сводится к тавтологичности импликации.
- [ ] $A \models B$ тогда и только тогда, когда $\models B \to A$ :: Направление импликации другое.
- [ ] Из $A \to B$ и $B$ следует $A$ :: Это ошибка «утверждение следствия», а не теорема.
