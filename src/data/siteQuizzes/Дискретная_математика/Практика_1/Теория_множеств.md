title: Проверь себя: от множеств к числам
description: Булеан и мощность, операции, парадокс Рассела, натуральные числа фон Неймана, рекурсивное сложение, пары Куратовского и целые числа.

? Пусть $A = \{1, 2, 3\}$. Какие записи верны?
- [x] $\{1, 2\} \subset A$ :: Оба элемента есть в $A$, а 3 — лишний, значит включение строгое.
- [x] $A \subseteq A$ :: Любое множество — нестрогое подмножество себя.
- [ ] $A \subset A$ :: Строгое подмножество не может совпадать с исходным.
- [ ] $1 \subseteq A$ :: Для элемента пишут $1 \in A$.

? Чему равен булеан пустого множества $2^{\varnothing}$?
- [ ] $\varnothing$ :: У $\varnothing$ есть одно подмножество — оно само.
- [x] $\{\varnothing\}$ :: Множество из одного элемента — пустого множества; $|2^\varnothing| = 2^0 = 1$.
- [ ] $\{\varnothing, \{\varnothing\}\}$ :: Это булеан множества $\{\varnothing\}$.

? Что показывает парадокс Рассела про «множество всех множеств, не содержащих себя»?
- [x] Не любой «набор по условию» можно считать множеством — нужна аксиоматика :: И $R \in R$, и $R \notin R$ ведут к противоречию.
- [ ] Что такое множество пусто :: Пустота противоречия не снимает.
- [ ] Что булеан больше самого множества :: Это другая теорема (Кантора).

? Как фон Нейман определяет натуральные числа?
- [x] $0 = \varnothing$, а $n + 1 = n \cup \{n\}$ — каждое число есть множество всех меньших :: Например, $2 = \{0, 1\}$.
- [ ] $0 = \varnothing$, $n + 1 = \{n\}$ :: Это первая попытка Цермело.
- [ ] $n$ — множество из $n$ одинаковых элементов :: В множестве нет повторений.

? Сколько элементов в числе 5 по фон Нейману? Введите число.
= 5
correct: $5 = \{0, 1, 2, 3, 4\}$ — ровно 5 элементов.
wrong: Число $n$ по фон Нейману — множество всех меньших чисел: $5 = \{0, 1, 2, 3, 4\}$, в нём 5 элементов.

? Откуда берётся множество всех натуральных чисел $\mathbb{N}$?
- [x] Его существование постулирует аксиома бесконечности :: Из правила $n^+$ оно само не выводится.
- [ ] Это самое большое натуральное число :: $\mathbb{N}$ — не натуральное число.
- [ ] Это булеан нуля :: $2^0 = \{\varnothing\} = 1$.

? Как рекурсивно определено сложение $S(a, b)$?
- [x] $S(a, 0) = a$; при $b \ne 0$: $S(a, b) = S(a, b^-)^+$ :: Рекурсия по второму аргументу через предшественника.
- [ ] $S(a, b) = a \cup b$ :: Объединение $\{0,1\} \cup \{0,1,2\}$ даёт 3, а не $2 + 3$.
- [ ] $S(a, b) = |a \times b|$ :: Это умножение по мощности, а не сложение.

? Что такое упорядоченная пара по Куратовскому?
- [x] $(a, b) := \{\{a\}, \{a, b\}\}$ :: По ней однозначно восстанавливается, кто первый.
- [ ] $(a, b) := \{a, b\}$ :: Тогда $(1, 2) = (2, 1)$ — порядок теряется.
- [ ] $(a, b) := \{\{a, b\}\}$ :: Порядок тоже не различается.

? Целые числа заданы парами $\langle a, b \rangle$ (смысл $a - b$). Какое условие равенства $\langle a_1, b_1 \rangle$ и $\langle a_2, b_2 \rangle$?
- [x] $a_1 + b_2 = a_2 + b_1$ :: Проверка без вычитания — только сложение натуральных.
- [ ] $a_1 = a_2$ и $b_1 = b_2$ :: $\langle 0, 1 \rangle$ и $\langle 2, 3 \rangle$ — разные пары, но одно число $-1$.
- [ ] $a_1 - b_1 = a_2 - b_2$ :: Вычитания в $\mathbb{N}$ ещё нет — его как раз и строим.
