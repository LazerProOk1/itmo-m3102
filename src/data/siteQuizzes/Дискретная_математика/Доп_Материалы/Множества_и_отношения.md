title: Проверь себя: множества и отношения (доп. материалы)
description: Включение и равенство множеств, замыкания и сокращения отношений, виды порядков, максимальные и наибольшие элементы, диаграммы Хассе.

? Верно ли $\{5\} \subseteq \{7, \{5\}\}$?
- [ ] Да: пятёрка есть справа :: Справа лежит не число 5, а множество $\{5\}$.
- [x] Нет: единственный элемент слева — число 5, а справа лежат 7 и множество $\{5\}$ :: Зато верно $\{5\} \in \{7, \{5\}\}$.

? Какие равенства верны?
- [x] $\{2, \{\square, \square, \square\}, 2\} = \{2, \{\square\}\}$ :: Повторы не важны ни снаружи, ни во вложенном множестве.
- [x] $\{\triangle, a, \{5\}\} = \{a, \{5\}, \triangle\}$ :: Порядок записи не важен.
- [ ] $\{6, \varnothing\} = \{6\}$ :: Слева два элемента: 6 и пустое множество.

? Чему равно симметричное замыкание отношения $R$?
- [x] $R \cup R^{-1}$ :: Для каждой пары добавляем перевёрнутую.
- [ ] $R \cup \mathrm{id}$ :: Это рефлексивное замыкание.
- [ ] $R \cap R^{-1}$ :: Пересечение убирает пары, а замыкание только добавляет.

? Как получить минимальную эквивалентность, содержащую $R$?
- [x] $\big((R^{=})^{\sim}\big)^{+}$ — транзитивное замыкание последним :: Иначе симметризация может разрушить транзитивность.
- [ ] Сначала транзитивное замыкание, потом симметричное :: После симметризации появятся новые цепочки, и транзитивность нарушится.
- [ ] Достаточно рефлексивного замыкания :: Эквивалентность требует ещё симметричности и транзитивности.

? Что такое частичный порядок?
- [x] Рефлексивное, антисимметричное и транзитивное отношение :: Например, $\le$ на числах или $\subseteq$ на множествах.
- [ ] Рефлексивное, симметричное и транзитивное :: Это эквивалентность.
- [ ] Рефлексивное и транзитивное :: Это предпорядок.

? Чем максимальный элемент отличается от наибольшего?
- [x] Над максимальным нет других элементов, а наибольший больше всех; максимальных может быть несколько :: В частичном порядке не все элементы сравнимы.
- [ ] Ничем, это синонимы :: Совпадают только в линейном порядке.
- [ ] Наибольших может быть несколько, а максимальный один :: Наоборот.

? Делимость на $\{2, 3, 4, 6\}$. Сколько там максимальных элементов? Введите число.
= 2
correct: 4 и 6: ни одно из чисел множества не делится на них, кроме них самих. Наибольшего элемента нет.
wrong: Элемент максимален, если он не делит никакой другой элемент. 2 делит 4, 3 делит 6, а 4 и 6 никого не делят — максимальных два, и наибольшего нет.

? Какие рёбра рисуют на диаграмме Хассе?
- [x] Только пары покрытия: $b$ покрывает $a$, если $a < b$ и между ними нет промежуточных элементов :: Это транзитивное сокращение порядка без петель.
- [ ] Все пары $a \le b$ :: Тогда граф был бы перегружен транзитивными рёбрами и петлями.
- [ ] Только петли $\langle a, a \rangle$ :: Петли как раз не рисуют.
