title: Проверь себя: матрицы
description: Индексы и размерность, единичная матрица, сложение, равенство, умножение на число, транспонирование, произведение и схема Фалька.

? Что означает элемент $a_{23}$?
- [x] Элемент во 2-й строке и 3-м столбце :: Сначала строка, потом столбец.
- [ ] Элемент в 3-й строке и 2-м столбце :: Частая ошибка — перепутать порядок индексов.
- [ ] Произведение $a_2 \cdot a_3$ :: Индексы — это координаты, а не множители.

? Матрица имеет 3 строки и 5 столбцов. Как записывается её размерность?
- [x] $3 \times 5$ :: Сначала число строк $m$, потом столбцов $n$.
- [ ] $5 \times 3$ :: Это размерность транспонированной матрицы.
- [ ] $15$ :: Это число элементов.

? Когда можно сложить матрицы $A$ и $B$?
- [x] Только при одинаковой размерности :: Сложение поэлементное.
- [ ] Когда число столбцов $A$ равно числу строк $B$ :: Это условие для умножения.
- [ ] Всегда :: Сумма $2 \times 2$ и $3 \times 3$ не определена.

? $A$ размера $2 \times 3$. Какой размер у $A^T$?
- [x] $3 \times 2$ :: Строки становятся столбцами.
- [ ] $2 \times 3$ :: Размерность меняется местами.
- [ ] $3 \times 3$ :: Число элементов не меняется: $2 \cdot 3 = 3 \cdot 2$.

? Как считается элемент $c_{ij}$ произведения $C = AB$?
- [x] $c_{ij} = \sum_h a_{ih} b_{hj}$ — $i$-я строка $A$ на $j$-й столбец $B$ :: Схема Фалька помогает не запутаться.
- [ ] $c_{ij} = a_{ij} \cdot b_{ij}$ :: Это поэлементное произведение, а не матричное.
- [ ] $c_{ij} = \sum_h a_{hi} b_{jh}$ :: Индексы перепутаны.

? $A = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix}$, $B = \begin{pmatrix} 3 & 0 \\ 1 & 2 \end{pmatrix}$. Чему равен элемент $(AB)_{11}$? Введите число.
= 5
correct: Первая строка $A$ на первый столбец $B$: $1 \cdot 3 + 2 \cdot 1 = 5$.
wrong: $(AB)_{11} = a_{11}b_{11} + a_{12}b_{21} = 1 \cdot 3 + 2 \cdot 1 = 5$.

? Какие утверждения верны?
- [x] В общем случае $AB \ne BA$ :: Умножение матриц некоммутативно.
- [x] Если $AB = BA$, матрицы называют перестановочными :: Например, любая матрица перестановочна с $E$.
- [x] У единичной матрицы $E$ единицы на главной диагонали и нули вне её :: $AE = EA = A$.
- [ ] Равные матрицы могут иметь разную размерность :: Равенство поэлементное, размерности обязаны совпадать.
