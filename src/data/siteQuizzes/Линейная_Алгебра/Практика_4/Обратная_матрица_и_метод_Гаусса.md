title: Проверь себя: обратная матрица и метод Гаусса
description: Определение обратной матрицы, матрица поворота, транспонирование произведения, дельта Кронекера, классификация СЛАУ и метод Гаусса.

? Что такое обратная матрица $A^{-1}$?
- [x] Матрица, для которой $AA^{-1} = A^{-1}A = E$ :: Произведение должно давать $E$ с обеих сторон.
- [ ] Матрица с элементами $\frac{1}{a_{ij}}$ :: Поэлементные обратные — это не обратная матрица.
- [ ] Транспонированная матрица :: Совпадает с обратной лишь у особых матриц, например у матрицы поворота.

? У каких матриц может быть обратная?
- [x] Только у квадратных :: У прямоугольных обратной не бывает.
- [ ] У любых :: Для $2 \times 3$ нельзя получить $E$ с обеих сторон.
- [ ] Только у диагональных :: Обратимы и многие недиагональные, например $\begin{pmatrix} 1 & 1 \\ 2 & 3 \end{pmatrix}$.

? Для $A = \begin{pmatrix} 1 & 1 \\ 2 & 3 \end{pmatrix}$ найдите элемент $(A^{-1})_{11}$. Введите число.
= 3
correct: $A^{-1} = \begin{pmatrix} 3 & -1 \\ -2 & 1 \end{pmatrix}$.
wrong: Решите $AX = E$ или используйте формулу для $2 \times 2$: $\det A = 1$, $A^{-1} = \begin{pmatrix} 3 & -1 \\ -2 & 1 \end{pmatrix}$, значит $(A^{-1})_{11} = 3$.

? Чему равна обратная к матрице поворота $A(\alpha) = \begin{pmatrix} \cos\alpha & -\sin\alpha \\ \sin\alpha & \cos\alpha \end{pmatrix}$?
- [x] $A(-\alpha)$, она же $A^T$ :: Поворот обратно на тот же угол; обратную можно не вычислять, достаточно транспонировать.
- [ ] $A(2\alpha)$ :: Это поворот ещё на $\alpha$, а не обратно.
- [ ] $-A(\alpha)$ :: Это поворот на $\alpha + \pi$.

? Чему равно $(AB)^T$?
- [x] $B^T A^T$ :: Порядок множителей меняется на противоположный.
- [ ] $A^T B^T$ :: Частая ошибка.
- [ ] $AB$ :: Произведение в общем случае не симметрично.

? Чему равна дельта Кронекера $\delta_{ij}$?
- [x] 1 при $i = j$ и 0 при $i \ne j$ :: Единичная матрица — это $E = (\delta_{ij})$.
- [ ] $i \cdot j$ :: Это просто произведение индексов.
- [ ] 1 всегда :: Тогда матрица целиком из единиц.

? Как классифицируются СЛАУ?
- [x] Совместная определённая — ровно одно решение :: Метод Гаусса доводит до единственного ответа.
- [x] Совместная неопределённая — бесконечно много решений :: Решения выражаются через параметры.
- [x] Несовместная — решений нет :: При Гауссе появляется строка $0 = b$, $b \ne 0$.
- [ ] Бывает система ровно с двумя решениями :: У СЛАУ решений 0, 1 или бесконечно много.

? Что делают в методе Гаусса с расширенной матрицей $(A \mid B)$?
- [x] Элементарными преобразованиями строк приводят её к ступенчатому виду, затем находят неизвестные с конца :: Каждая строка — одно уравнение.
- [ ] Переставляют столбцы, пока $A$ не станет единичной :: Перестановка столбцов меняет порядок неизвестных и не основной приём.
- [ ] Транспонируют её :: Транспонирование меняет смысл системы.
