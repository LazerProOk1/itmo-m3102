title: Проверь себя: комплексные числа на практике
description: Рейтинг по практике, действия в алгебраической форме, деление через сопряжённое, корни и показательная форма.

? Сколько баллов за семестр по практике линала дают оценку «3» без экзамена?
- [x] 60 :: А «4» — от 74 баллов, если пороги не изменятся.
- [ ] 50 :: Ниже порога «3».
- [ ] 74 :: Это порог «4».

? Чему равно $(1 + 2i)(3 - i)$?
- [x] $5 + 5i$ :: $3 - i + 6i - 2i^2 = 3 + 5i + 2 = 5 + 5i$.
- [ ] $3 - 2i$ :: Перемножены только «одноимённые» части.
- [ ] $1 + 5i$ :: Забыли, что $-2i^2 = +2$.

? Как разделить $z_1$ на $z_2$?
- [x] Домножить числитель и знаменатель на $\overline{z_2}$ — знаменатель станет вещественным $|z_2|^2$ :: Дальше делим каждую часть на вещественное число.
- [ ] Разделить отдельно вещественные и мнимые части :: $\frac{a+bi}{c+di} \ne \frac ac + \frac bd i$.
- [ ] Домножить на $z_2$ :: Знаменатель $z_2^2$ в общем случае не вещественный.

? Чему равна вещественная часть $\frac{1}{1 + i}$? Введите десятичную дробь.
= 0.5 | 0,5 | 1/2
correct: $\frac{1}{1+i} = \frac{1 - i}{(1+i)(1-i)} = \frac{1 - i}{2}$, вещественная часть $\frac12$.
wrong: Домножьте на сопряжённое: $\frac{1}{1+i} \cdot \frac{1-i}{1-i} = \frac{1-i}{2} = \frac12 - \frac12 i$.

? Какие утверждения о корнях $n$-й степени из $z \ne 0$ верны?
- [x] Все корни имеют одинаковый модуль $\sqrt[n]{|z|}$ :: Они лежат на одной окружности.
- [x] Соседние корни отличаются по аргументу на $\frac{2\pi}{n}$ :: Корни — вершины правильного $n$-угольника.
- [ ] При $k = n$ получается новый корень :: $k = n$ повторяет случай $k = 0$.
- [ ] Корень из комплексного числа всегда один :: Их ровно $n$.

? Какие корни четвёртой степени у числа 1?
- [x] $1,\ i,\ -1,\ -i$ :: Вершины квадрата на единичной окружности.
- [ ] Только $1$ и $-1$ :: Это только вещественные корни.
- [ ] $1,\ 2,\ 3,\ 4$ :: Модуль всех корней равен 1.

? Почему в показательной форме $z = |z|e^{i\varphi}$ удобно умножать?
- [x] $|z_1|e^{i\varphi_1} \cdot |z_2|e^{i\varphi_2} = |z_1||z_2| e^{i(\varphi_1 + \varphi_2)}$ — работают обычные правила степеней :: Модули перемножаются, углы складываются.
- [ ] Потому что мнимая часть исчезает :: Она «спрятана» в угле, а не исчезает.
- [ ] Потому что $e^{i\varphi}$ всегда вещественно :: $e^{i\pi/2} = i$.

? Можно ли пользоваться гаджетами на контрольных по практике?
- [ ] Да, любыми :: На контрольных — только записи.
- [x] Нет, только записями :: Гаджеты можно использовать на обычных парах.
