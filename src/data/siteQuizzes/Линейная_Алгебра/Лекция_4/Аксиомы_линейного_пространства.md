title: Проверь себя: аксиомы линейного пространства
description: Восемь аксиом, нулевой вектор и ноль поля, единственность нейтрального и обратного, примеры пространств, транспонирование и умножение матриц.

? Сколько аксиом в определении линейного пространства? Введите число.
= 8
correct: 4 аксиомы сложения, 2 — умножения на скаляр, 2 — дистрибутивность.
wrong: Аксиом восемь: коммутативность и ассоциативность сложения, нулевой и обратный элементы, ассоциативность умножения на скаляр, $1 \cdot x = x$ и две дистрибутивности.

? Какие из этих равенств — аксиомы линейного пространства?
- [x] $1 \cdot x = x$ :: Нормировка единицей поля.
- [x] $(\alpha + \beta) x = \alpha x + \beta x$ :: Дистрибутивность по скалярам.
- [x] $\alpha(\beta x) = (\alpha\beta)x$ :: Ассоциативность умножения на скаляр.
- [ ] $x \cdot y = y \cdot x$ для векторов :: Умножения векторов друг на друга в определении нет.

? Чем $\theta$ отличается от $0$?
- [x] $\theta$ — нулевой вектор из $V$, а $0$ — ноль поля $K$ :: Разные объекты, хотя в $K^n$ их легко спутать.
- [ ] Ничем, это два обозначения одного и того же :: Вектор и скаляр — объекты разных множеств.
- [ ] $\theta$ — пустое множество :: Это вектор, а не множество.

? Как доказывается единственность нулевого вектора?
- [x] Если $\theta_1$ и $\theta_2$ нулевые, то $\theta_1 = \theta_1 + \theta_2 = \theta_2$ :: Сумму считаем двумя способами.
- [ ] Это отдельная аксиома :: Аксиома даёт только существование.
- [ ] Через умножение на скаляр $0$ :: Это следствие доказывают отдельно.

? Чему равно $0 \cdot x$ для любого вектора $x$?
- [x] $\theta$ :: Следствие из аксиом: $0 \cdot x = (0 + 0)x = 0x + 0x$.
- [ ] $0$ из поля :: Результат умножения скаляра на вектор — вектор.
- [ ] $x$ :: Это $1 \cdot x$.

? Матрица $A$ размера $2 \times 3$, $B$ — $3 \times 4$. Какого размера $AB$?
- [x] $2 \times 4$ :: Строк как у $A$, столбцов как у $B$.
- [ ] $3 \times 3$ :: Общая размерность 3 «съедается» при умножении.
- [ ] Произведение не определено :: Определено: столбцов у $A$ столько же, сколько строк у $B$.

? Что верно для кольца квадратных матриц $M_n$?
- [x] Умножение ассоциативно :: $A(BC) = (AB)C$.
- [x] Есть единица — матрица $E_n = (\delta_{ij})$ :: Единицы на главной диагонали.
- [ ] Умножение коммутативно :: В общем случае $AB \ne BA$.

? Чему равно $(A^T)^T$?
- [x] $A$ :: Двойное транспонирование возвращает матрицу.
- [ ] $A^{-1}$ :: Транспонирование не обращает матрицу.
- [ ] $-A$ :: Знаки элементов не меняются.
