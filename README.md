# М3102 — учебное пространство группы

Сайт группы М3102 (ИТМО): расписание, домашние задания, дедлайны, конспекты и материалы в одном месте.
Работает в браузере без сервера — личные отметки и учебный план хранятся на устройстве.

**Сайт:** https://lazerprook1.github.io/itmo-m3102/

## Что есть

- **Главная** — пары на сегодня, ближайшие дедлайны и ДЗ, предметы, закладки, недавние конспекты. И ёжик.
- **Расписание** — по неделям и дням, чётные/нечётные недели, переносы и замены, ДЗ прямо в карточке пары;
  **календарь** с событиями.
- **Домашнее задание** — общее для группы, отметка «сделано» у каждого своя.
- **Дедлайны** — сроки сдачи и общая очередь (через GitHub issues).
- **Предметы** — страница предмета: занятия, конспекты, материалы, ссылки, контакты преподавателей.
- **Материалы** — конспекты группы и 1 потока, учебники (PDF), записи лекций, лабораторные, полезные ссылки.
- **Читалка конспектов** — формулы, схемы, содержание, навигация по лекциям, прогресс чтения, закладки,
  пометки в тексте, печать.
- **Тесты** — к конспектам группы (свои тесты сайта подписаны «Тест сделан на этом сайте»), повторение
  по интервалам (1/3/7/14 дней) и режим экзамена по предмету.
- **Личное** — учебный план, заметки, задачи; хранятся только в этом браузере.
- **Поиск** по тексту конспектов (включая код и PDF), ДЗ, ссылкам и студентам (`Ctrl+K`), горячие клавиши (`?`).
- **Студенты** и **мемы** группы.
- **Оформление** — светлая и тёмная тема, цвет акцента, живой фон и свечения (выключаются в настройках).
- **Офлайн** — сайт ставится как приложение (PWA) и открывается без сети: конспекты уже на устройстве,
  открытые PDF — в кеше.

## Откуда данные

Кнопка «Синхронизировать» в шапке подтягивает конспекты, материалы, дедлайны, ДЗ и ссылки из
[RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102), а конспекты 1 потока — из
[Kefirleos/itmo-vault](https://github.com/Kefirleos/itmo-vault). При открытии сайта это происходит само,
не чаще раза в 10 минут; неизменённые файлы повторно не скачиваются (сверка по sha).

Сервера нет: всё, что синхронизировано, и все личные данные лежат в `localStorage` браузера. Другие устройства
их не видят, очистка данных сайта их удаляет. План сервера с входом через ITMO ID — [docs/BACKEND_PLAN.md](docs/BACKEND_PLAN.md).

Форматы файлов те же, что у RedstoneLord: `Конспекты/{Предмет}/{Лекция_N}/…`, `Дедлайны/deadlines.json`,
`data/homework.json`, `data/links.json`, `data/memes.json`.

## Ветки

- `react-app` (по умолчанию) — сайт только для просмотра, публикуется на GitHub Pages.
- `react-app-dev` — то же, но с режимом редактирования: правка расписания, конспектов, ДЗ (с публикацией
  в GitHub по токену), мемов и ссылок.
- `legacy` — копия `master` из [RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102) со старым
  статическим сайтом. Обновляется кнопкой **Actions → «Синхронизировать legacy с RedstoneLord» → Run workflow**
  (и автоматически раз в сутки).

## Разработка

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run format:check
npm run build
```

React 19, TypeScript, Vite, Zustand, Framer Motion. Пуш в `react-app` — CI проверяет форматирование, тесты
и сборку и публикует на GitHub Pages.

Подробная инструкция для разработки — в [CLAUDE.md](CLAUDE.md).
