# М3102

Расписание, дедлайны, ДЗ, конспекты и тесты группы М3102 (ИТМО) в одном месте.

[![CI](https://img.shields.io/github/actions/workflow/status/LazerProOk1/itmo-m3102/deploy-pages.yml?branch=react-app&label=CI)](https://github.com/LazerProOk1/itmo-m3102/actions/workflows/deploy-pages.yml)
[![Сайт](https://img.shields.io/badge/%D1%81%D0%B0%D0%B9%D1%82-lazerprook1.github.io-5b6cf9)](https://lazerprook1.github.io/itmo-m3102/)

</div>

Сайт работает в браузере без сервера и регистрации, ставится как приложение и открывается без интернета.
Данные берутся из репозиториев группы на GitHub, личное хранится только на устройстве.

## Возможности

- **Расписание** — неделя по часам на ПК и список по дням на телефоне, чётные недели, переносы и замены, ДЗ в карточке пары.
- **Главная** — блоки можно переставить и скрыть, выбрать плотность и страницу, которая открывается при запуске.
- **Календарь** — пары, свои события, дедлайны группы и ДЗ в день сдачи. Подписка для Google и Apple Календаря
  обновляется сама.
- **Дедлайны** — сроки и общая очередь на сдачу через GitHub Issues.
- **Конспекты** — по папкам занятий, читалка с формулами, схемами и оглавлением, PDF, закладки и пометки в тексте,
  печать без обрезанных формул.
- **Схемы** — графы, деревья, массивы с пошаговым выполнением кода и редактор, где узлы двигаются мышью.
- **Тесты** — к конспектам, с повторением ошибок через 1, 3, 7 и 14 дней и режимом экзамена.
- **Поиск** по тексту всех конспектов, включая PDF (`Ctrl+K`). Все горячие клавиши — по `?`.
- **Личное** — учебный план, заметки и отметки «сделано» только в этом браузере.
- **Для ИИ** — все конспекты предмета одним Markdown-файлом, чтобы отдать ChatGPT или Claude.
- **Ёжик М3102** — маскот: бегает по шапке главной, сидит в пустых списках, выглядывает, когда закрыто всё, и иногда наряжается к празднику.

## Установка как приложение

- Android, Chrome: меню → «Установить приложение».
- iPhone, Safari: «Поделиться» → «На экран „Домой“».
- ПК, Chrome или Edge: значок установки в адресной строке.

Первый раз сайт нужно открыть с интернетом. Дальше он обновляется сам, а без сети показывает сохранённое.

## Конспекты для ИИ

На странице предмета кнопка «Для ИИ» скачивает или копирует один файл: описание курса, оглавление, все конспекты
группы и 1 потока по порядку занятий, текст PDF и ссылки на материалы. ИИ читает всё сразу и не тратит токены
на поиск по сайту. Размер — примерно 50–75 тысяч токенов на предмет.

## Календарь в телефоне

«В календарь» на страницах расписания и календаря. Подписка (`webcal://…/m3102.ics`) — пары с переносами
и заменами, дедлайны и ДЗ группы; файл пересобирается раз в сутки и при каждом обновлении сайта, Apple подтягивает
изменения за несколько часов, Google — до суток. «Скачать .ics» — разовый снимок, в нём ещё свои события и задачи.

## Что дальше

- **Связи между сущностями.** Пара, конспект занятия, ДЗ, дедлайн, тест и заметка знают друг о друге: из карточки
  пары — конспект и ДЗ к ней, из дедлайна — материалы и очередь, из конспекта — когда следующее занятие.
- **Полноценная страница предмета.** Всё по предмету в одном месте: ближайшие пары, преподаватели, баллы и формула
  оценки, дедлайны, ДЗ, конспекты по папкам, тесты и прогресс подготовки к экзамену.
- **Главная «Сегодня».** Короткий ответ на «что мне делать сейчас»: следующая пара и что взять, горящие сроки,
  что повторить, — с учётом выбранных на главной блоков.
- **Расширенный глобальный поиск.** Фильтры по предмету и типу (конспект, ДЗ, дедлайн, тест, заметка), поиск
  по формулам и подписям схем, быстрые действия прямо из поиска.
- **Мобильная версия.** Жесты в читалке, офлайн-доступ к выбранным предметам целиком, виджет «следующая пара»,
  уведомления о сроках от установленного приложения.

## Откуда данные

- Конспекты, ДЗ, дедлайны, расписание, ссылки и мемы — [RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102).
- Конспекты 1 потока — [Kefirleos/itmo-vault](https://github.com/Kefirleos/itmo-vault).
- Очередь на сдачу — GitHub Issues репозитория группы.

Синхронизация идёт при открытии сайта, не чаще раза в 10 минут, и по кнопке в шапке. Без токена у GitHub API
лимит 60 запросов в час на сеть.

Личное (отметки, учебный план, заметки, пометки, результаты тестов) лежит в `localStorage` и не покидает браузер.
План сервера со входом через ITMO ID — в [docs/BACKEND_PLAN.md](docs/BACKEND_PLAN.md).

## Разработка

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # юнит-тесты
npm run test:e2e     # тесты в браузере
npm run build
```

React, TypeScript, Vite, Zustand. Пуш в `react-app` проверяется в CI (форматирование, тесты, размер сборки,
Lighthouse) и публикуется на GitHub Pages. Правила, устройство кода и принятые решения — в [AGENTS.md](AGENTS.md).
