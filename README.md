# М3102 — учебное пространство группы

Сайт группы М3102 (ИТМО): расписание, домашние задания, дедлайны, конспекты и материалы в одном месте.
Работает в браузере без сервера — личные отметки и учебный план хранятся на устройстве.

**Сайт:** https://lazerprook1.github.io/itmo-m3102/

## Что есть

- **Главная** — приветствие дня, пары на сегодня, ближайшие дедлайны и ДЗ, учебный план, недавние конспекты. И ёжик.
- **Расписание** — по неделям и дням, чётные/нечётные недели, ДЗ прямо в карточке пары.
- **Домашнее задание** — общее для группы, отметка «сделано» у каждого своя.
- **Дедлайны** — сроки сдачи и общая очередь (через GitHub issues).
- **Материалы** — конспекты группы и 1 потока (читалка с содержанием и навигацией по лекциям), учебники,
  записи лекций, лабораторные, полезные ссылки.
- **Поиск** по тексту всех конспектов, ДЗ, ссылкам и студентам (`Ctrl+K`).
- **Студенты** и **мемы** группы.

## Откуда данные

Кнопка «Синхронизировать» в шапке подтягивает конспекты, материалы, дедлайны, ДЗ и ссылки из
[RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102), а конспекты 1 потока — из
[Kefirleos/itmo-vault](https://github.com/Kefirleos/itmo-vault). При открытии сайта это происходит само.

Форматы файлов те же, что у RedstoneLord: `Конспекты/{Предмет}/{Лекция_N}/…`, `Дедлайны/deadlines.json`,
`data/homework.json`, `data/links.json`, `data/memes.json`.

## Ветки

- `react-app` (по умолчанию) — сайт только для просмотра, публикуется на GitHub Pages.
- `react-app-dev` — то же, но с режимом редактирования: правка расписания, конспектов, ДЗ (с публикацией
  в GitHub по токену), мемов и ссылок.
- `master` — legacy: копия [RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102) со старым
  статическим сайтом. Обновляется кнопкой **Actions → «Синхронизировать master с RedstoneLord» → Run workflow**
  (и автоматически раз в сутки).
