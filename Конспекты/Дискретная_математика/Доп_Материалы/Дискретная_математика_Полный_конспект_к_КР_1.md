# Дискретная математика: полный конспект к КР №1

## 1. Язык и методы доказательства

### Логические обозначения

:::meaning
- $P \Rightarrow Q$ — «из $P$ следует $Q$».
- $P \Leftrightarrow Q$ — «$P$ тогда и только тогда, когда $Q$» (равносильность): верны оба утверждения, $P \Rightarrow Q$ и $Q \Rightarrow P$.
- $\forall x$ — «для любого $x$»; $\exists x$ — «существует такой $x$».
- $\neg P$ — «неверно, что $P$».
:::

:::remember
Как отрицать утверждения с кванторами:
- $\neg(\forall x\ P(x))$ означает $\exists x\ \neg P(x)$: чтобы опровергнуть «для всех», достаточно **одного** $x$, для которого $P(x)$ ложно (**контрпример**);
- $\neg(\exists x\ P(x))$ означает $\forall x\ \neg P(x)$: чтобы опровергнуть «существует», нужно проверить **все** $x$.
:::

### Основные методы доказательства

| Метод | Идея | Где встречается |
|---|---|---|
| Прямое доказательство | из условий шаг за шагом получаем вывод | эквивалентность дробей |
| Цепочка равносильностей | преобразуем условие в равносильные, пока не получим нужное | $\mathcal{P}(A \cap B) = \mathcal{P}(A) \cap \mathcal{P}(B)$ |
| Двойное включение | для равенства множеств доказываем $A \subseteq B$ и $B \subseteq A$ | равенства множеств |
| От противного | предполагаем обратное и получаем противоречие | ящики, рукопожатия, бесконечность простых |
| Контрпример | один пример опровергает утверждение «для всех» | свойства отношений, $\mathcal{P}(A \cup B)$ |
| Индукция | доказываем базу и переход $k \to k+1$ | неравенства, делимость |
| Раскраска (инвариант) | находим величину, которую нельзя получить | шахматная доска |

:::note
Для доказательства $P \Rightarrow Q$ можно доказывать равносильное ему утверждение $\neg Q \Rightarrow \neg P$ (**контрапозицию**). Иногда так проще: нужно предположить, что вывод ложен, и показать, что тогда ложно условие.
:::

## 2. Множества

### Основные понятия

:::meaning
**Множество** — совокупность различных объектов (элементов). Множество определяется своими элементами: порядок и повторы не важны, $\{1,2,2,1\} = \{1,2\}$.

- $x \in A$ — $x$ является **элементом** $A$.
- $A \subseteq B$ — $A$ — **подмножество** $B$: каждый элемент $A$ лежит в $B$.
- $\varnothing$ — **пустое множество**, у него нет элементов.
- $A = B$ тогда и только тогда, когда $A \subseteq B$ и $B \subseteq A$.
:::

:::remember
Для любого множества $A$ верно $\varnothing \subseteq A$ и $A \subseteq A$.
:::

### Элемент и подмножество — разные понятия

Элементами множества могут быть другие множества. Сравните:

| Множество | Количество элементов | Элементы |
|---|---|---|
| $\varnothing$ | 0 | нет |
| $\{\varnothing\}$ | 1 | $\varnothing$ |
| $\{\{\varnothing\}\}$ | 1 | $\{\varnothing\}$ |

:::warning
- $\varnothing \neq \{\varnothing\}$: у первого нет элементов, у второго есть один.
- $\{\varnothing\} \in \{\{\varnothing\}\}$ верно, а $\{\varnothing\} \subseteq \{\{\varnothing\}\}$ — нет (для этого нужно $\varnothing \in \{\{\varnothing\}\}$).
- Чтобы проверить $A \subseteq B$, смотрите на **элементы** $A$; чтобы проверить $A \in B$, ищите **само** $A$ среди элементов $B$.
:::

### Операции над множествами

:::meaning
- **Объединение:** $A \cup B = \{x \mid x \in A \text{ или } x \in B\}$.
- **Пересечение:** $A \cap B = \{x \mid x \in A \text{ и } x \in B\}$.
- **Разность:** $A \setminus B = \{x \mid x \in A \text{ и } x \notin B\}$.
- **Декартово произведение:** $A \times B = \{(a,b) \mid a \in A,\ b \in B\}$ — множество упорядоченных пар. Если $|A| = m$, $|B| = n$, то $|A \times B| = mn$.
:::

:::note
Пары упорядочены: $(1,2) \ne (2,1)$. Отношение на множестве $A$ — подмножество $A \times A$ (см. раздел 3).
:::

Стандартные законы (для подмножеств универсального множества $U$, дополнение $\overline{A} = U \setminus A$):

| Закон | Формула |
|---|---|
| Коммутативность | $A \cup B = B \cup A$, $A \cap B = B \cap A$ |
| Дистрибутивность | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$, $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ |
| Законы де Моргана | $\overline{A \cup B} = \overline{A} \cap \overline{B}$, $\overline{A \cap B} = \overline{A} \cup \overline{B}$ |
| Разность через дополнение | $A \setminus B = A \cap \overline{B}$ |

### Как доказывать равенство множеств

:::example
Чтобы доказать $X = Y$, берём произвольный элемент и действуем одним из двух способов.

**Двойное включение.**
1. Пусть $x \in X$. Показываем, что $x \in Y$. Значит, $X \subseteq Y$.
2. Пусть $x \in Y$. Показываем, что $x \in X$. Значит, $Y \subseteq X$.
3. Из двух включений следует $X = Y$.

**Цепочка равносильностей.** Записываем $x \in X \iff \ldots \iff x \in Y$, где на каждом шаге переход допустим в обе стороны.
:::

### Булеан

:::meaning
**Булеан** $\mathcal{P}(A)$ — множество всех подмножеств $A$ (включая $\varnothing$ и само $A$).

Ключевое правило: $X \in \mathcal{P}(Y) \iff X \subseteq Y$.
:::

:::remember
Если в $A$ ровно $n$ элементов, то $|\mathcal{P}(A)| = 2^n$.

Причина: для каждого из $n$ элементов независимо выбираем, входит он в подмножество или нет, — два варианта на каждый элемент, всего $2 \cdot 2 \cdots 2 = 2^n$.
:::

Примеры:

- $\mathcal{P}(\varnothing) = \{\varnothing\}$ — один элемент ($2^0 = 1$);
- $\mathcal{P}(\{\varnothing\}) = \{\varnothing, \{\varnothing\}\}$ — два элемента ($2^1 = 2$);
- $\mathcal{P}(\{a,b\}) = \{\varnothing, \{a\}, \{b\}, \{a,b\}\}$ — четыре элемента.

Диаграмма включений между элементами $\mathcal{P}(\{a,b,c\})$ (соединены подмножества, различающиеся одним элементом; $2^3 = 8$ вершин):

### Булеан и операции

:::formula
$$
\mathcal{P}(A \cap B) = \mathcal{P}(A) \cap \mathcal{P}(B) \quad \text{— верно для любых } A, B.
$$
:::

Доказательство цепочкой равносильностей: 

$$
X \in \mathcal{P}(A \cap B) \iff X \subseteq A \cap B \iff (X \subseteq A \text{ и } X \subseteq B) \iff X \in \mathcal{P}(A) \cap \mathcal{P}(B).
$$

Для объединения верно только включение:

$$
\mathcal{P}(A) \cup \mathcal{P}(B) \subseteq \mathcal{P}(A \cup B).
$$

:::warning
Равенство $\mathcal{P}(A \cup B) = \mathcal{P}(A) \cup \mathcal{P}(B)$ **неверно** в общем случае. Контрпример: $A = \{a,b\}$, $B = \{b,c\}$. Множество $\{a,c\}$ лежит в $\mathcal{P}(A \cup B)$, но не лежит ни в $\mathcal{P}(A)$ (так как $c \notin A$), ни в $\mathcal{P}(B)$ (так как $a \notin B$).

Причина: подмножество объединения может брать элементы и из $A$, и из $B$, а подмножество пересечения обязано лежать в обоих множествах.
:::

:::example
**Как проверять принадлежность $X \in \mathcal{P}(\mathcal{P}(U))$.** Для $U = \{a,b,c\}$ и $X = \{\varnothing, \{a,b\}\}$:
1. $X \in \mathcal{P}(\mathcal{P}(U))$ равносильно $X \subseteq \mathcal{P}(U)$.
2. Это значит: каждый элемент $X$ должен лежать в $\mathcal{P}(U)$, то есть быть подмножеством $U$.
3. Элементы $X$: $\varnothing \subseteq U$ и $\{a,b\} \subseteq U$ — оба подходят. Утверждение верно.

Для $X = \{a, \{b\}\}$ и вопроса $X \in \mathcal{P}(U)$ нужно $X \subseteq U$. Элемент $\{b\}$ не является элементом $U$, поэтому утверждение ложно.
:::

## 3. Отношения

### Определение

:::meaning
**Бинарное отношение** $R$ на множестве $A$ — подмножество $A \times A$, то есть некоторый набор упорядоченных пар элементов. Запись $xRy$ означает $(x,y) \in R$.

Отношение можно задать:
- перечислением пар: $R = \{(1,2),(2,3)\}$;
- условием: $xRy \iff x < y$, $xRy \iff x \mid y$ ($x$ делит $y$);
- рисунком: элементы — вершины, пара $(x,y)$ — стрелка $x \to y$.
:::

### Семь свойств

:::meaning
Пусть $R$ — отношение на $A$.

| Свойство | Определение | Как выглядит на рисунке |
|---|---|---|
| **Рефлексивность** | $xRx$ для всех $x \in A$ | петля у каждой вершины |
| **Иррефлексивность** | $xRx$ не выполнено ни для одного $x$ | нет ни одной петли |
| **Симметричность** | $xRy \Rightarrow yRx$ | у каждой стрелки есть обратная |
| **Антисимметричность** | $xRy$ и $yRx \Rightarrow x = y$ | нет пар встречных стрелок между разными вершинами |
| **Асимметричность** | $xRy \Rightarrow$ не $yRx$ | нет петель и нет встречных стрелок |
| **Транзитивность** | $xRy$ и $yRz \Rightarrow xRz$ | к любому пути $x \to y \to z$ есть «короткая» стрелка $x \to z$ |
| **Тотальность** | для всех $x \neq y$: $xRy$ или $yRx$ | любые две различные вершины соединены стрелкой хотя бы в одну сторону |
:::

:::warning
- **Рефлексивность и иррефлексивность — не противоположности.** Отношение $\{(1,1),(1,2)\}$ на $\{1,2,3\}$ не рефлексивно ($2R2$ нет) и не иррефлексивно ($1R1$ есть).
- **Антисимметричность разрешает петли**, асимметричность — нет.
- **Вакуумная истинность.** Если нет ни одной пары, нарушающей условие «если … то …», свойство выполнено. Отношение $x < y$ антисимметрично, потому что в нём нет пар $xRy$ и $yRx$ одновременно.
- **Тотальность** проверяется только для различных элементов, пары $(x,x)$ на неё не влияют.
- **Транзитивность** надо проверять и для цепочек, возвращающихся в начало: если $1R2$ и $2R1$, то нужно $1R1$.
:::

### Как проверять свойство

:::example
1. Если нужно **доказать** свойство, проверяем все случаи (все элементы, все пары, все цепочки из двух стрелок) или рассуждаем в общем виде по определению.
2. Если нужно **опровергнуть**, достаточно **одного контрпримера** — конкретных $x$, $y$ (и $z$), на которых нарушено определение. В ответе всегда называйте эти элементы.
3. Для тотальности ищите пару различных элементов без стрелки в обе стороны. Для транзитивности ищите путь $x \to y \to z$ без стрелки $x \to z$. Для симметричности ищите стрелку без обратной.
:::

### Связи между свойствами

:::remember
- Асимметричность $\iff$ иррефлексивность и антисимметричность одновременно.
- Если отношение одновременно симметрично и антисимметрично, то в нём есть только пары вида $(x,x)$: из $xRy$ следует $yRx$, а затем $x = y$.
- Пустое отношение $\varnothing$ иррефлексивно, симметрично, антисимметрично, асимметрично и транзитивно (все условия выполнены вакуумно), но не рефлексивно (при непустом $A$) и не тотально (при $|A| \geq 2$).
:::

### Эталонные примеры

Все отношения заданы на $A = \{1,2,3\}$, кроме делимости (на $\{1,2,3,6\}$). Знак «+» — свойство выполнено, «−» — нет.

| Отношение | Реф. | Иррефл. | Сим. | Антис. | Асим. | Тран. | Тот. |
|---|---|---|---|---|---|---|---|
| $x = y$ | + | − | + | + | − | + | − |
| $x \neq y$ | − | + | + | − | − | − | + |
| $x < y$ | − | + | − | + | + | + | + |
| $x \mid y$ (на $\{1,2,3,6\}$) | + | − | − | + | − | + | − |
| $\{(1,2),(2,3)\}$ | − | + | − | + | + | − | − |
| $\{(1,1),(2,2),(3,3),(1,2),(2,1)\}$ | + | − | + | − | − | + | − |
| $A \times A$ | + | − | + | − | − | + | + |
| $\{(1,1),(1,2)\}$ | − | − | − | + | − | + | − |

Основные контрпримеры для этих отношений:

- $x = y$: нет тотальности — $1 \neq 2$, но ни $1R2$, ни $2R1$.
- $x \neq y$: нет транзитивности — $1R2$ и $2R1$, но $1R1$ не выполнено; нет антисимметричности — $1R2$ и $2R1$ при $1 \neq 2$.
- $x < y$: нет симметричности — $1R2$, но не $2R1$.
- $x \mid y$: нет симметричности — $1 \mid 2$, но $2 \nmid 1$; нет тотальности — $2 \nmid 3$ и $3 \nmid 2$.
- $\{(1,2),(2,3)\}$: нет транзитивности — $1R2$, $2R3$, но $(1,3) \notin R$.

```quiz
- [x] Иррефлексивность :: Из $xRx$ следовало бы «не $xRx$» — противоречие.

explain: Асимметричность равносильна иррефлексивности вместе с антисимметричностью.

- [ ] Оно пусто :: Пары $(x,x)$ допустимы.

- [ ] Потому что оно не рефлексивно :: Рефлексивность к транзитивности не относится.

explain: Контрпример для транзитивности — путь из двух стрелок без стрелки напрямик.
```

## 4. Отношение эквивалентности

### Определение

:::meaning
Отношение $\sim$ на множестве $A$ называется **отношением эквивалентности**, если оно:
1. **рефлексивно:** $a \sim a$ для всех $a$;
2. **симметрично:** $a \sim b \Rightarrow b \sim a$;
3. **транзитивно:** $a \sim b$ и $b \sim c \Rightarrow a \sim c$.

Эти три свойства нужно доказывать **по отдельности**, а затем сделать вывод.
:::

### Пример: равенство дробей

Рассмотрим множество формальных дробей

$$
F = \{(a,b) \in \mathbb{Z} \times \mathbb{Z} \mid b \neq 0\}, \qquad \frac{a}{b} \sim \frac{c}{d} \iff ad = bc.
$$

:::note
Формальная дробь — это просто пара целых чисел со знаменателем $b \neq 0$. Как пары $\frac{1}{2}$ и $\frac{2}{4}$ различны, но $\frac{1}{2} \sim \frac{2}{4}$, потому что $1 \cdot 4 = 2 \cdot 2$.
:::

:::example
**Рефлексивность.** Нужно $ab = ba$. Это верно в силу коммутативности умножения.

**Симметричность.** Пусть $ad = bc$. Нужно $cb = da$. Имеем $cb = bc = ad = da$.

**Транзитивность.** Пусть $ad = bc$ и $cf = de$. Нужно $af = be$.
1. Умножим $ad = bc$ на $f$: $adf = bcf$.
2. Умножим $cf = de$ на $b$: $bcf = bde$.
3. Значит, $adf = bde$, то есть $d(af - be) = 0$.
4. Знаменатель $d \neq 0$, а в $\mathbb{Z}$ нет делителей нуля. Поэтому $af - be = 0$, то есть $af = be$.

**Вывод.** Отношение рефлексивно, симметрично и транзитивно, значит $\sim$ — отношение эквивалентности на $F$.
:::

:::warning
Сокращать при доказательстве транзитивности можно на $d$ (знаменатель, $d \neq 0$ по определению $F$). На числитель $c$ сокращать нельзя — он может быть нулём.
:::

### Класс эквивалентности

:::meaning
**Класс эквивалентности** элемента $a$ — множество всех элементов, эквивалентных $a$:

$$
[a] = \{x \in A \mid x \sim a\}.
$$
:::

:::formula
Для формальных дробей: $\dfrac{a}{b} \sim \dfrac{ka}{kb}$ при любом целом $k \neq 0$.

Доказательство: $kb \neq 0$ (как произведение ненулевых чисел), и $a \cdot kb = b \cdot ka = kab$.
:::

:::example
**Класс дроби $\frac{1}{2}$.** Дробь $\frac{c}{d}$ эквивалентна $\frac{1}{2}$ тогда и только тогда, когда $1 \cdot d = 2 \cdot c$, то есть $d = 2c$. Так как $d \neq 0$, то $c \neq 0$. Поэтому

$$
\left[\tfrac{1}{2}\right] = \left\{\frac{c}{2c} \;\middle|\; c \in \mathbb{Z},\ c \neq 0\right\} = \left\{\ldots, \frac{-1}{-2}, \frac{1}{2}, \frac{2}{4}, \frac{3}{6}, \ldots\right\}.
$$
:::

### Теорема о классах эквивалентности

:::remember
Пусть $\sim$ — эквивалентность на $A$. Тогда:
1. $a \in [a]$ для любого $a$ (рефлексивность);
2. $a \sim b \iff [a] = [b]$;
3. два различных класса не пересекаются, а объединение всех классов равно $A$.

То есть эквивалентность **разбивает** множество на непересекающиеся классы.
:::

:::example
**Доказательство пункта 2.**
- Пусть $a \sim b$ и $x \in [a]$, то есть $x \sim a$. Из $x \sim a$ и $a \sim b$ по транзитивности $x \sim b$, значит $x \in [b]$. Итак, $[a] \subseteq [b]$. Из симметричности $b \sim a$ аналогично получаем $[b] \subseteq [a]$. Значит, $[a] = [b]$.
- Если $[a] = [b]$, то $a \in [a] = [b]$, то есть $a \sim b$.

**Доказательство пункта 3.** Если $c \in [a] \cap [b]$, то $c \sim a$ и $c \sim b$. По симметричности и транзитивности $a \sim b$, значит, по пункту 2 $[a] = [b]$. Поэтому два класса либо совпадают, либо не пересекаются.
:::

Пример разбиения: отношение $\{(1,1),(2,2),(3,3),(1,2),(2,1)\}$ на множестве $\{1,2,3\}$ рефлексивно, симметрично и транзитивно, то есть является эквивалентностью. Его классы: $\{1,2\}$ и $\{3\}$.

## 5. Комбинаторные приёмы

### 5.1. Принцип Дирихле

:::remember
**Принцип Дирихле.** Если $n$ предметов разложены по $k$ ящикам, то в каком-то ящике окажется не менее $\lceil n/k \rceil$ предметов. В частности, при $n > k$ найдётся ящик, где не менее двух предметов.
:::

:::meaning
Запись $\lceil x \rceil$ — наименьшее целое число, не меньшее $x$ (округление вверх): $\lceil 21/5 \rceil = \lceil 4{,}2 \rceil = 5$.
:::

:::example
**Задача.** 21 предмет нельзя разложить по пяти коробкам так, чтобы в каждой было не больше четырёх.

1. Предположим, что можно: в каждой коробке не больше $4$ предметов.
2. Тогда всего предметов не больше $5 \cdot 4 = 20$.
3. Но по условию их $21 > 20$ — противоречие.
4. Значит, в некоторой коробке не меньше $5$ предметов.
:::

```chart bar

Всего предметов: 21
```

:::note
Схема применения: определите, что здесь «предметы» и что «ящики», оцените, сколько предметов вместится при ограничении, и сравните с реальным числом.
:::

### 5.2. Лемма о рукопожатиях

Знакомства в компании моделируются графом: люди — вершины, пара знакомых — ребро. Число знакомых человека — **степень** вершины.

:::remember
**Лемма о рукопожатиях.** Сумма степеней всех вершин равна удвоенному числу рёбер, поэтому она чётна. Следовательно, число вершин нечётной степени всегда чётно. В частности, в компании не может быть ровно одного человека с нечётным числом знакомых.
:::

:::example
**Доказательство.** Знакомство взаимно, и никто не знаком с самим собой.
1. Сложим числа знакомых по всей компании: сумма $S$.
2. Каждая пара знакомых даёт в $S$ ровно $2$ единицы (по одной для каждого). Значит, $S = 2 \cdot (\text{число пар знакомых})$ — чётное.
3. Если бы нечётное число знакомых было ровно у одного человека, то в сумме все слагаемые, кроме одного, были бы чётными, и сумма была бы нечётной — противоречие.
:::

### 5.3. Раскраска и инвариант

:::meaning
**Инвариант** — величина или свойство, которое не меняется при допустимых действиях. Если для нужного результата инвариант должен быть другим, результат недостижим.

В задачах о покрытии доску часто **раскрашивают** так, чтобы каждая фигура покрывала фиксированный набор цветов.
:::

:::example
**Шахматная доска $8 \times 8$ без двух противоположных углов не покрывается домино.**
1. Раскрасим доску в шахматном порядке: 32 тёмных и 32 светлых клетки.
2. Костяшка закрывает две соседние клетки, а они разного цвета, поэтому каждая костяшка закрывает ровно одну тёмную и одну светлую клетку. Любое покрытие закрывает поровну тёмных и светлых клеток.
3. Противоположные углы (например, $a1$ и $h8$) одного цвета. После их удаления остаётся $30$ клеток одного цвета и $32$ — другого.
4. Поровну быть не может, значит покрытие невозможно.
:::

:::warning
Важно, что удалены именно **противоположные** углы: они одного цвета. При удалении соседних углов цвета были бы разные, и рассуждение не сработало бы.
:::

## 6. Математическая индукция

### Принцип и схема

:::remember
**Принцип математической индукции.** Утверждение $P(n)$ верно для всех целых $n \geq n_0$, если:
1. **база:** $P(n_0)$ верно;
2. **шаг:** для любого $k \geq n_0$ из $P(k)$ (предположение индукции) следует $P(k+1)$.

Образ: падающие костяшки домино — упала первая и каждая падающая валит следующую, значит упадут все.
:::

```diagram
title: Схема доказательства по индукции
A: round "База: проверить P(n0)"
B: box "Предположить, что P(k) верно (k ≥ n0)"
C: box "Шаг: доказать P(k+1), используя P(k)"
D: round "Вывод: P(n) верно для всех n ≥ n0"
A -> B
B -> C
C -> D
```

:::warning
- **Без базы нельзя:** шаг сам по себе не доказывает утверждение, ему не от чего «запуститься».
- В шаге **обязательно используйте предположение индукции** $P(k)$ — иначе это не индукция.
- Условие $k \geq n_0$ входит в шаг и иногда нужно по ходу (например, в оценке $2k + 2 \geq k + 2$ нужно $k \geq 0$).
- Предположение индукции — для **одного** $k$, а не «для всех $n$»: нельзя пользоваться тем, что надо доказать.
:::

### Пример 1: неравенство $2^n \geq n + 1$ при $n \geq 0$

:::example
**База ($n = 0$).** $2^0 = 1 \geq 1 = 0 + 1$.

**Предположение.** Пусть $2^k \geq k + 1$ для некоторого $k \geq 0$.

**Шаг.** Докажем $2^{k+1} \geq k + 2$.
1. $2^{k+1} = 2 \cdot 2^k$.
2. По предположению $2 \cdot 2^k \geq 2(k+1) = 2k + 2$.
3. Так как $k \geq 0$, имеем $2k + 2 \geq k + 2$.
4. Итого $2^{k+1} \geq k + 2$.
:::

```plot
title: 2^x и x + 1 (равенство при n = 0 и n = 1)
x: -1..4 y: 0..9 grid
y = 2^x {color: blue, label: "2^x"}
y = x + 1 {color: red, label: "x + 1"}
point (0, 1) "n = 0"
point (1, 2) "n = 1"
```

### Пример 2: делимость $n^3 + 2n$ на $3$ при $n \geq 1$

:::example
**База ($n = 1$).** $1 + 2 = 3$ делится на $3$.

**Предположение.** Пусть $k^3 + 2k$ делится на $3$ для некоторого $k \geq 1$.

**Шаг.** Преобразуем выражение для $k+1$ так, чтобы в нём выделилась часть из предположения:

$$
(k+1)^3 + 2(k+1) = k^3 + 3k^2 + 3k + 1 + 2k + 2 = (k^3 + 2k) + 3(k^2 + k + 1).
$$

Первое слагаемое делится на $3$ по предположению, второе содержит множитель $3$. Значит, вся сумма делится на $3$.
:::

:::note
Приёмы для шага индукции:
- **Делимость:** раскройте выражение для $k+1$ и выделите выражение для $k$ плюс слагаемое, явно кратное нужному числу.
- **Неравенство:** примените предположение индукции к части выражения, затем оцените остаток (в том числе используя $k \geq n_0$).
:::


## 7. Простые числа

### Основные понятия

:::meaning
**Простое число** — натуральное число $p > 1$, которое делится только на $1$ и на само себя. Натуральное число $n > 1$, не являющееся простым, называется **составным**. Число $1$ не простое и не составное.
:::

:::remember
**Основная теорема арифметики.** Каждое натуральное число, большее $1$, раскладывается в произведение простых чисел, причём это разложение единственно с точностью до порядка множителей.

Следствие (из существования разложения): у любого натурального числа $n > 1$ есть простой делитель.
:::

### Бесконечность множества простых чисел

:::formula
**Теорема (Евклид).** Самого большого простого числа не существует.
:::

:::example
**Доказательство от противного.**
1. Предположим, что простых чисел конечное число: $p_1, p_2, \ldots, p_n$.
2. Рассмотрим $N = p_1 p_2 \cdots p_n + 1$. Оно больше $1$, значит у него есть простой делитель $q$.
3. Так как в списке все простые числа, $q = p_i$ для некоторого $i$.
4. Тогда $q$ делит $p_1 p_2 \cdots p_n$ и делит $N$, а значит делит и их разность $N - p_1 p_2 \cdots p_n = 1$.
5. Простое число не может делить $1$ — противоречие. Значит, простых чисел бесконечно много.
:::

:::warning
Число $N = p_1 \cdots p_n + 1$ **не обязано быть простым**; доказательство показывает лишь, что у него есть простой делитель вне списка. Например, $2 \cdot 3 \cdot 5 \cdot 7 \cdot 11 \cdot 13 + 1 = 30031 = 59 \cdot 509$ — составное.
:::

```quiz
title: Проверка: простые числа

? Какое из чисел простое?
- [ ] $1$ :: У числа 1 только один делитель, оно не считается простым.
- [ ] $51$ :: $51 = 3 \cdot 17$.
- [x] $53$ :: Единственные делители $53$ — это $1$ и $53$.
- [ ] $91$ :: $91 = 7 \cdot 13$.
explain: Простое число — натуральное число больше $1$ ровно с двумя делителями.

? Верно ли, что число $p_1 p_2 \cdots p_n + 1$ всегда простое?
- [ ] Да, иначе доказательство Евклида не работало бы :: Доказательству достаточно простого делителя этого числа.
- [x] Нет :: Например, $2 \cdot 3 \cdot 5 \cdot 7 \cdot 11 \cdot 13 + 1 = 30031 = 59 \cdot 509$.
explain: Важно лишь то, что у $N$ есть простой делитель, не входящий в список.

? Почему простое число $q$ не может делить сразу $p_1 \cdots p_n$ и $p_1 \cdots p_n + 1$?
- [ ] Потому что они взаимно просты по определению простых :: Это не определение, а следствие рассуждения.
- [x] Тогда $q$ делило бы их разность, равную $1$ :: Простое число $q \geq 2$ не делит $1$.
- [ ] Потому что $N$ не делится на простые числа :: Любое число, большее 1, имеет простой делитель.
explain: Это ключевой шаг, приводящий к противоречию.
```

## 8. Памятка к экзамену

### Тип задачи, метод, ключевые шаги

| Тип задачи | Метод | Что обязательно написать |
|---|---|---|
| Верно ли $X \in Y$ или $X \subseteq Y$ | выписать элементы | элементы $Y$, затем есть ли среди них $X$ (для $\in$) или все ли элементы $X$ лежат в $Y$ (для $\subseteq$) |
| Вычислить булеан | перечислить подмножества | число элементов $2^n$ как проверка |
| $X \in \mathcal{P}(\mathcal{P}(U))$ | свести к включению | $X \subseteq \mathcal{P}(U)$, затем каждый элемент $X$ — подмножество $U$ |
| Равенство множеств | двойное включение или равносильности | два включения / цепочка с двусторонними переходами |
| Опровергнуть равенство | контрпример | конкретные множества и элемент, лежащий только в одной части |
| Свойства отношения | определения и контрпримеры | для невыполненных свойств — конкретные элементы |
| Доказать эквивалентность | три свойства | отдельные доказательства и вывод |
| Класс эквивалентности | решить условие $x \sim a$ | множество решений в явном виде |
| «Нельзя / не может быть» | от противного | предположение, вывод, противоречие |
| Ящики | принцип Дирихле | что «предметы», что «ящики», оценка |
| Знакомства, рукопожатия | сумма степеней | сумма чётна как удвоенное число пар |
| Покрытие фигурами | раскраска | что закрывает каждая фигура и чего не хватает |
| Для всех $n \geq n_0$ | индукция | база, предположение, шаг с использованием предположения, вывод |

### Частые ошибки

:::warning
1. Путают $\in$ и $\subseteq$, $\varnothing$ и $\{\varnothing\}$.
2. Считают, что $\mathcal{P}(A \cup B) = \mathcal{P}(A) \cup \mathcal{P}(B)$ всегда верно.
3. Не приводят **конкретный** контрпример для невыполненного свойства отношения.
4. Считают, что «не рефлексивно» значит «иррефлексивно».
5. Забывают проверять транзитивность на цепочках вида $xRy$, $yRx$ (должно быть $xRx$).
6. Сокращают на числитель при доказательстве транзитивности равенства дробей, хотя можно только на знаменатель.
7. В индукции не доказывают базу или не используют предположение индукции.
8. В доказательстве Евклида утверждают, что $p_1 \cdots p_n + 1$ — простое.
:::

```quiz
title: Итоговый тест: подготовка к КР №1

? Какое утверждение верно?
- [ ] $\{\varnothing\} \subseteq \{\{\varnothing\}\}$ :: Для этого нужно, чтобы $\varnothing$ лежало в $\{\{\varnothing\}\}$, но оно там не лежит.
- [x] $\{\varnothing\} \in \{\{\varnothing\}\}$ :: Единственный элемент правого множества — $\{\varnothing\}$.
- [ ] $\varnothing \in \{\{\varnothing\}\}$ :: Единственный элемент правого множества — $\{\varnothing\}$, а не $\varnothing$.
explain: Знак $\in$ спрашивает, является ли множество элементом; знак $\subseteq$ — лежат ли его элементы в другом множестве.

? Для каких равенств выполнено условие «верно для любых $A$ и $B$»?
- [x] $\mathcal{P}(A \cap B) = \mathcal{P}(A) \cap \mathcal{P}(B)$ :: Подмножество лежит в пересечении тогда и только тогда, когда лежит и в $A$, и в $B$.
- [ ] $\mathcal{P}(A \cup B) = \mathcal{P}(A) \cup \mathcal{P}(B)$ :: Контрпример: $\{a,c\}$ при $A = \{a,b\}$, $B = \{b,c\}$.
- [ ] $\mathcal{P}(A \cap B) = \mathcal{P}(A) \cup \mathcal{P}(B)$ :: В правой части лежат подмножества $A$, не лежащие в $B$.
explain: Для объединения верно лишь включение $\mathcal{P}(A) \cup \mathcal{P}(B) \subseteq \mathcal{P}(A \cup B)$.

? Какие свойства имеет отношение $x \neq y$ на множестве $\{1,2,3\}$?
- [ ] Рефлексивность :: $1 \ne 1$ ложно, значит $1R1$ нет.
- [x] Симметричность :: Если $x \neq y$, то $y \neq x$.
- [x] Тотальность :: Любые два различных элемента связаны отношением.
- [ ] Транзитивность :: $1R2$ и $2R1$, но $1R1$ нет.
explain: Отношение «не равно» иррефлексивно, симметрично и тотально, но не транзитивно и не антисимметрично.

? Сколько классов эквивалентности порождает дробь $\frac{1}{2}$ вместе с дробью $\frac{3}{6}$? Введите целое число.
= 1
correct: Дроби эквивалентны ($1 \cdot 6 = 2 \cdot 3$) и лежат в одном классе.
wrong: Проверка: $1 \cdot 6 = 6$ и $2 \cdot 3 = 6$, поэтому дроби эквивалентны и дают один и тот же класс.

? В какой-то из коробок окажется не менее скольких предметов, если 21 предмет разложен по 5 коробкам? Введите целое число.
= 5
correct: $\lceil 21/5 \rceil = 5$, так как $5 \cdot 4 = 20 < 21$.
wrong: Пять коробок по четыре предмета вмещают лишь 20 предметов, поэтому в какой-то коробке не менее 5.

? Почему на шахматной доске без двух противоположных углов нельзя разместить костяшки домино без пропусков?
- [ ] Осталось нечётное число клеток :: Осталось 62 клетки, их число чётно.
- [x] Осталось 30 клеток одного цвета и 32 другого, а костяшка закрывает по одной клетке каждого цвета :: Покрытие требует равенства числа клеток разных цветов.
- [ ] Удалены клетки разного цвета :: Противоположные углы доски одного цвета.
explain: Это пример доказательства раскраской.

? Какое неравенство используется в шаге индукции для $2^n \geq n + 1$ и требует условия $k \geq 0$?
- [ ] $2^{k+1} \geq 2^k$ :: Оно верно, но не приводит к нужной оценке и не использует предположение индукции.
- [x] $2k + 2 \geq k + 2$ :: Разность равна $k$, неотрицательна при $k \geq 0$.
- [ ] $k + 1 \geq k + 2$ :: Это неравенство ложно при любом $k$.
explain: После применения предположения индукции остаётся оценить $2k + 2$ снизу числом $k + 2$.

? Почему простое число $q$, делящее $p_1 \cdots p_n + 1$, не совпадает ни с одним из $p_i$?
- [ ] Потому что $q$ больше всех $p_i$ по определению :: Это не определение, а вывод, к которому доказательство приходит.
- [x] Иначе $q$ делило бы и $p_1 \cdots p_n$, и $N$, а значит и $1$ :: Простое число не делит $1$.
- [ ] Потому что $N$ простое :: Число $N$ не обязано быть простым.
explain: Из этого противоречия следует, что простых чисел больше, чем в любом конечном списке.
```
