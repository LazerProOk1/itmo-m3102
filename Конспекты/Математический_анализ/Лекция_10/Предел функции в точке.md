# Предел функции в точке

Рассматривается функция $f: E \to \mathbb{R}$, где $E \subset \mathbb{R}$, и точка $x_0$, являющаяся **предельной точкой** множества $E$.

:::meaning
**Предельная точка множества $E$** — точка $x_0$, в любой окрестности которой есть точки множества $E$, отличные от $x_0$. Сама точка $x_0$ может как принадлежать $E$, так и не принадлежать ему: именно поэтому предел определяется через значения функции *вблизи* $x_0$, но не *в самой* $x_0$.
:::

Используем два обозначения окрестностей:

- $U_\varepsilon(a) = (a - \varepsilon,\; a + \varepsilon)$ — $\varepsilon$-окрестность точки $a$ (на оси значений);
- $\mathring{U}_\delta(x_0) = \{x : 0 < |x - x_0| < \delta\}$ — **проколотая** $\delta$-окрестность точки $x_0$ (на оси аргументов): интервал $(x_0 - \delta,\; x_0 + \delta)$ без самой точки $x_0$.

## Определение предела функции

### Определение по Коши

:::meaning
Число $a$ называется **пределом** функции $f(x)$ при $x \to x_0$, если

$$
\forall \varepsilon > 0 \;\; \exists \delta_\varepsilon > 0 : \;\; 0 < |x - x_0| < \delta_\varepsilon \;\Rightarrow\; |f(x) - a| < \varepsilon .
$$

Здесь $x \in E$, а запись $\delta_\varepsilon$ подчёркивает, что число $\delta$ подбирается в зависимости от $\varepsilon$.
:::

Это определение «на языке $\varepsilon$–$\delta$». Его же можно записать на языке окрестностей:

$$
\lim_{x \to x_0} f(x) = a \iff \forall \varepsilon > 0 \;\; \exists \delta_\varepsilon > 0 : \;\; x \in \mathring{U}_{\delta}(x_0) \;\Rightarrow\; f(x) \in U_\varepsilon(a) .
$$

Смысл: какую бы маленькую $\varepsilon$-окрестность числа $a$ мы ни задали, найдётся такая проколотая $\delta$-окрестность точки $x_0$, что все значения функции в ней попадают в заданную $\varepsilon$-окрестность $a$.

```plot
title: Предел при x → x₀: значения f(x) в δ-окрестности лежат в ε-окрестности числа a
x: 0..4 y: 0..4 grid
y = 2 + 0.25*(x-2)^3 {color: blue, label: "y = f(x)"}
y = 2.03125 {color: red, dashed}
y = 1.96875 {color: red, dashed}
x = 1.5 {color: green, dashed}
x = 2.5 {color: green, dashed}
point (2, 2) "(x₀, a)"
```

:::note
На графике ось $Ox$ — аргумент, ось $Oy$ — значение функции. Красные горизонтальные линии ограничивают $\varepsilon$-окрестность $U_\varepsilon(a)$ числа $a$ на оси $Oy$, зелёные вертикальные — окрестность точки $x_0$ на оси $Ox$. Для всех $x$ из этой окрестности, кроме самой точки $x_0$, график лежит между красными линиями. В точке $x_0$ функция может быть вообще не определена или иметь другое значение — на предел это не влияет.
:::

:::warning
Условие $0 < |x - x_0|$ существенно: точка $x = x_0$ из рассмотрения **исключена**. Значение $f(x_0)$ (и даже его существование) не участвует в определении предела.
:::

### Определение по Гейне

:::meaning
$$
\lim_{x \to x_0} f(x) = a \iff \text{для любой последовательности } \{x_n\} \text{ такой, что } x_n \in E,\; x_n \neq x_0 \;\; \forall n,\; x_n \xrightarrow[n \to \infty]{} x_0, \;\text{ выполнено }\; \lim_{n \to \infty} f(x_n) = a .
$$
:::

Иначе говоря, предел функции в точке — это общий предел значений $f(x_n)$ вдоль **любой** последовательности точек из $E$, сходящейся к $x_0$ и не равной $x_0$.

:::remember
В определении по Гейне на последовательность $\{x_n\}$ наложены три условия: $x_n \in E$, $x_n \neq x_0$ для всех $n$ и $x_n \to x_0$. Результат $\lim f(x_n) = a$ должен получаться для **каждой** такой последовательности и быть одним и тем же числом $a$.
:::

```quiz

- [x] $x_n \to x_0$ при $n \to \infty$

```

## Равносильность определений по Коши и по Гейне

:::remember
**Теорема.** Определения предела по Коши и по Гейне равносильны.
:::

### Доказательство: Коши $\Rightarrow$ Гейне

Пусть $\lim\limits_{x \to x_0} f(x) = a$ по Коши, то есть

$$
\forall \varepsilon > 0 \;\; \exists \delta > 0 : \;\; 0 < |x - x_0| < \delta \;\Rightarrow\; |f(x) - a| < \varepsilon .
$$

Возьмём произвольную последовательность $\{x_n\}$, $x_n \in E$, $x_n \neq x_0$, $x_n \to x_0$. Так как $x_n \to x_0$, то для найденного $\delta_\varepsilon$ существует номер $N$ такой, что

$$
\forall n > N: \quad |x_n - x_0| < \delta_\varepsilon .
$$

Поскольку к тому же $x_n \neq x_0$, то $0 < |x_n - x_0| < \delta_\varepsilon$, и по определению Коши

$$
|f(x_n) - a| < \varepsilon \quad \forall n > N .
$$

Так как $\varepsilon > 0$ произвольно, это и означает, что $\lim\limits_{n \to \infty} f(x_n) = a$.

### Доказательство: Гейне $\Rightarrow$ Коши

Доказываем от противного. Пусть $\lim\limits_{x \to x_0} f(x) = a$ по Гейне, но по Коши это неверно. Отрицание определения Коши:

$$
\exists \varepsilon > 0 \;\; \forall \delta > 0 \;\; \exists x \in E : \;\; 0 < |x - x_0| < \delta \;\text{ и }\; |f(x) - a| \geq \varepsilon .
$$

Берём $\delta_n = \dfrac{1}{n}$. Для каждого $n$ выберем точку $x_n \in E$ такую, что

$$
0 < |x_n - x_0| < \frac{1}{n} \quad \text{и} \quad |f(x_n) - a| \geq \varepsilon .
$$

Тогда $x_n \in E$, $x_n \neq x_0$ и $x_n \to x_0$, поэтому по определению Гейне $\lim\limits_{n \to \infty} f(x_n) = a$. Это значит, что

$$
\exists N : \;\; \forall n > N \;\; |f(x_n) - a| < \varepsilon .
$$

Но по построению $|f(x_n) - a| \geq \varepsilon$ при всех $n$ — противоречие. Следовательно, предел существует и по Коши. $\blacksquare$

:::note
Идея второй части: если «Коши» не выполняется, то при каждом сужающемся $\delta = \tfrac1n$ найдётся «плохая» точка $x_n$, в которой значение функции отстоит от $a$ не меньше чем на $\varepsilon$. Эти «плохие» точки образуют последовательность, сходящуюся к $x_0$, вдоль которой значения функции **не** стремятся к $a$, что противоречит определению Гейне.
:::

## Примеры

### Пример 1. Предел по Коши

Докажем по определению Коши, что

$$
\lim_{x \to 3} \left( x^2 - 2x \right) = 3 .
$$

:::example
Здесь $x_0 = 3$, $a = 3$. Пусть $\varepsilon > 0$. Нужно найти $\delta_\varepsilon$, для которого из $0 < |x - 3| < \delta_\varepsilon$ следует $|x^2 - 2x - 3| < \varepsilon$.

1. Разложим на множители: $x^2 - 2x - 3 = (x - 3)(x + 1)$. Тогда

$$
|f(x) - 3| = |x - 3| \cdot |x + 1| .
$$

2. Множитель $|x - 3|$ мы можем сделать малым. Множитель $|x + 1|$ надо оценить сверху константой. Для этого сначала ограничим $\delta$ числом $1$, то есть считаем $|x - 3| < 1$. Тогда

$$
|x + 1| = |(x - 3) + 4| \leq |x - 3| + 4 < 1 + 4 = 5 .
$$

3. Следовательно, при $|x - 3| < 1$ выполнено

$$
|f(x) - 3| < 5 \, |x - 3| .
$$

4. Чтобы правая часть была меньше $\varepsilon$, достаточно потребовать $|x - 3| < \dfrac{\varepsilon}{5}$.

5. Оба условия ($|x - 3| < 1$ и $|x - 3| < \tfrac{\varepsilon}{5}$) выполнены одновременно, если взять

$$
\delta_\varepsilon = \min\left( 1, \frac{\varepsilon}{5} \right) .
$$

Тогда из $0 < |x - 3| < \delta_\varepsilon$ следует $|f(x) - 3| < 5 \cdot \dfrac{\varepsilon}{5} = \varepsilon$, что и требовалось. $\blacksquare$
:::

:::warning
Типичная ошибка — пытаться оценить $|x + 1|$, не ограничив предварительно $|x - 3|$: пока $x$ может быть сколь угодно далёк от $3$, множитель $|x + 1|$ неограничен. Поэтому и появляется «два условия» на $\delta$ и минимум из двух чисел.
:::

### Пример 2. Функция $\sin\frac{1}{x}$ не имеет предела в нуле

Докажем, что у функции

$$
f(x) = \sin\frac{1}{x}, \qquad D(f) = E = \mathbb{R} \setminus \{0\},
$$

нет предела при $x \to 0$ (здесь $x_0 = 0$ — предельная точка $E$, но не принадлежит $E$).

```plot
title: График y = sin(1/x): колебания между −1 и 1 вблизи нуля
x: -0.6..0.6 y: -1.5..1.5 grid
y = sin(1/x) {color: blue, label: "sin(1/x)"}
y = 1 {color: gray, dashed}
y = -1 {color: gray, dashed}
point (0.3183, 0) "x₁"
point (0.1592, 0) "x₂"
point (0.1273, 1) "y₁"
point (0.0707, 1) "y₂"
```

Вблизи нуля график бесконечно часто колеблется между $-1$ и $1$ и не приближается ни к какому числу. Строго это доказывается по Гейне: достаточно найти две последовательности, сходящиеся к $0$, вдоль которых значения функции имеют **разные** пределы.

:::example
**Контрпример по Гейне.**

1. Первая последовательность: $x_n = \dfrac{1}{\pi n}$, $n = 1, 2, \dots$ Она сходится к $0$, $x_n \neq 0$, и

$$
\lim_{n \to \infty} f(x_n) = \lim_{n \to \infty} \sin(\pi n) = 0 .
$$

2. Вторая последовательность: $y_n = \dfrac{1}{\frac{\pi}{2} + 2\pi n}$, $n = 1, 2, \dots$ Она тоже сходится к $0$, $y_n \neq 0$, и

$$
f(y_n) = \sin\left( \frac{\pi}{2} + 2\pi n \right) = 1, \qquad \text{поэтому} \qquad \lim_{n \to \infty} f(y_n) = 1 .
$$

3. Две последовательности аргументов, стремящиеся к одной и той же точке $0$, дают разные пределы значений функции ($0 \neq 1$). Если бы предел $a$ существовал, по Гейне он должен был бы равняться и $0$, и $1$ одновременно. Значит, предела не существует. $\blacksquare$
:::

:::remember
**Приём:** чтобы доказать, что предела нет, по Гейне достаточно предъявить либо две последовательности $x_n \to x_0$, $y_n \to x_0$ (с $x_n, y_n \neq x_0$) такие, что $\lim f(x_n) \neq \lim f(y_n)$, либо одну последовательность, для которой $\lim f(x_n)$ не существует.
:::

### Пример 3. Функция Дирихле

Функция Дирихле:

$$
\chi(x) = \begin{cases} 1, & x \in \mathbb{Q}, \\ 0, & x \notin \mathbb{Q}. \end{cases}
$$

```plot
title: Функция Дирихле: значения 1 (рациональные x) и 0 (иррациональные x)
x: -3..3 y: -0.5..1.5 grid
y = 1 {color: blue, dashed, label: "x рациональное"}
y = 0 {color: red, dashed, label: "x иррациональное"}
```

:::note
Такой график нельзя нарисовать непрерывной линией: он состоит из «двух пунктирных прямых» $y = 1$ (в рациональных точках) и $y = 0$ (в иррациональных). Рациональные и иррациональные числа плотно перемешаны на всей оси.
:::

Докажем, что $\chi(x)$ не имеет предела ни в одной точке. Покажем это для точки $x_0 = 1$ (для любой другой точки рассуждение такое же).

:::example
1. Возьмём последовательность **рациональных** чисел $x_n = 1 + \dfrac{1}{n}$, $n = 1, 2, \dots$ Она сходится к $1$, $x_n \neq 1$, и $\chi(x_n) = 1$ при всех $n$, поэтому

$$
\lim_{n \to \infty} \chi(x_n) = 1 .
$$

2. Возьмём последовательность **иррациональных** чисел $y_n = 1 + \dfrac{1}{\sqrt{2}\, n}$, $n = 1, 2, \dots$ Она тоже сходится к $1$, $y_n \neq 1$, и $\chi(y_n) = 0$ при всех $n$, поэтому

$$
\lim_{n \to \infty} \chi(y_n) = 0 .
$$

3. Пределы вдоль двух последовательностей, сходящихся к одной точке, различны ($1 \neq 0$). По определению Гейне предела $\lim\limits_{x \to 1} \chi(x)$ не существует. $\blacksquare$
:::

:::note
Для произвольной точки $x_0$ рассуждение аналогично: в любой окрестности точки есть и рациональные, и иррациональные числа, поэтому можно взять одну последовательность из рациональных, а другую из иррациональных чисел, сходящиеся к $x_0$.
:::

## Локальные свойства пределов

### Локальная ограниченность

:::remember
**Теорема.** Пусть существует $\lim\limits_{x \to x_0} f(x) = a$. Тогда существует проколотая окрестность $\mathring{U}_\delta(x_0)$, на которой функция $f(x)$ ограничена.
:::

**Доказательство.** Возьмём $\varepsilon = 1 > 0$. По определению предела

$$
\exists \delta > 0 : \;\; 0 < |x - x_0| < \delta \;\Rightarrow\; |f(x) - a| < 1 .
$$

Для таких $x$ по неравенству треугольника

$$
|f(x)| = |(f(x) - a) + a| \leq |f(x) - a| + |a| < 1 + |a| .
$$

Положим $M = 1 + |a|$. Тогда $|f(x)| < M$ при всех $x \in \mathring{U}_\delta(x_0)$, то есть функция ограничена в этой окрестности. $\blacksquare$

```plot
title: Ограниченность в окрестности: |f(x)| < M = 1 + |a| при a = 2
x: -2..2 y: -4..4 grid
y = 2 + 0.5*sin(5*x) {color: blue, label: "f(x)"}
y = 3 {color: red, dashed, label: "M = 1 + |a|"}
y = -3 {color: red, dashed}
point (0, 2) "(x₀, a)"
```

:::warning
Ограниченность здесь **локальная**: она гарантируется только в некоторой окрестности точки $x_0$, а не на всей области определения. Размер окрестности ($\delta$) зависит от функции и найден при выборе $\varepsilon = 1$.
:::

### Теорема о сохранении знака

:::remember
**Теорема.** Если $\lim\limits_{x \to x_0} f(x) = a > 0$, то существует проколотая окрестность $\mathring{U}_\delta(x_0)$, такая что

$$
f(x) > 0 \quad \text{для всех } x \in \mathring{U}_\delta(x_0).
$$
:::

**Доказательство.** Возьмём $\varepsilon = \dfrac{a}{2} > 0$. По определению предела

$$
\exists \delta > 0 : \;\; 0 < |x - x_0| < \delta \;\Rightarrow\; |f(x) - a| < \frac{a}{2} .
$$

Раскроем модуль:

$$
|f(x) - a| < \frac{a}{2} \iff a - \frac{a}{2} < f(x) < a + \frac{a}{2} .
$$

Из левого неравенства $f(x) > \dfrac{a}{2} > 0$ для всех $x \in \mathring{U}_\delta(x_0)$, что и требовалось. $\blacksquare$

:::note
Доказательство даёт чуть больше: в окрестности значения функции не просто положительны, но и больше $\dfrac{a}{2}$. Выбор $\varepsilon = \dfrac{a}{2}$ нужен, чтобы $\varepsilon$-окрестность числа $a$ целиком лежала правее нуля.
:::

### Предельный переход в неравенствах

:::remember
**Теорема.** Пусть $f(x) \leq g(x)$ для всех $x$ из некоторой окрестности точки $x_0$, и существуют пределы $\lim\limits_{x \to x_0} f(x)$ и $\lim\limits_{x \to x_0} g(x)$. Тогда

$$
\lim_{x \to x_0} f(x) \leq \lim_{x \to x_0} g(x) .
$$
:::

**Доказательство** опирается на определение Гейне. Возьмём произвольную последовательность $\{x_n\}$, $x_n \to x_0$ при $n \to \infty$, $x_n \neq x_0$, из этой окрестности. Тогда $f(x_n) \leq g(x_n)$ при всех $n$. По теореме о предельном переходе в неравенствах для последовательностей

$$
\lim_{n \to \infty} f(x_n) \leq \lim_{n \to \infty} g(x_n) .
$$

По определению Гейне предел последовательности значений функции равен пределу функции в точке: $\lim\limits_{n \to \infty} f(x_n) = \lim\limits_{x \to x_0} f(x)$ и $\lim\limits_{n \to \infty} g(x_n) = \lim\limits_{x \to x_0} g(x)$. Отсюда получаем требуемое неравенство. $\blacksquare$

```quiz
title: Проверка: локальные свойства пределов

? Пусть $\lim\limits_{x \to x_0} f(x) = a$. Какое $\varepsilon$ берётся при доказательстве локальной ограниченности и какую границу оно даёт?
- [ ] $\varepsilon = \dfrac{a}{2}$, граница $\dfrac{a}{2}$ :: Это выбор в теореме о сохранении знака.
- [x] $\varepsilon = 1$, граница $M = 1 + |a|$ :: Из $|f(x) - a| < 1$ следует $|f(x)| < 1 + |a|$.
- [ ] $\varepsilon = |a|$, граница $2|a|$ :: Такой выбор не годится при $a = 0$.
explain: Оценка $|f(x)| \leq |f(x) - a| + |a| < 1 + |a|$ получается из неравенства треугольника.

? Пусть $\lim\limits_{x \to x_0} f(x) = a > 0$. Что можно утверждать о значениях функции вблизи $x_0$?
- [x] В некоторой проколотой окрестности $f(x) > \dfrac{a}{2}$
- [ ] Во всей области определения $f(x) > 0$ :: Свойство локальное и верно лишь в некоторой окрестности точки.
- [ ] $f(x_0) > 0$ :: Значение в точке $x_0$ может быть иным или не определено.
- [x] В некоторой проколотой окрестности $f(x) > 0$
explain: Выбор $\varepsilon = \dfrac{a}{2}$ даёт $a - \dfrac{a}{2} < f(x)$, то есть $f(x) > \dfrac{a}{2} > 0$ в окрестности точки $x_0$.

? Каким определением предела пользуются при доказательстве теоремы о предельном переходе в неравенствах для функций, сводя её к теореме для последовательностей?
- [ ] Только определением Коши :: Для перехода к последовательностям нужно определение Гейне.
- [x] Определением Гейне :: Берутся последовательности $x_n \to x_0$, и неравенство $f(x_n) \leq g(x_n)$ переносится на пределы.
- [ ] Никаким, достаточно значений в точке $x_0$ :: Значения в самой точке $x_0$ для предела не используются.
explain: Предел функции вдоль любой последовательности $x_n \to x_0$ равен пределу функции в точке.
```

```quiz
title: Итоговый тест: предел функции в точке

? Какая запись соответствует определению предела по Коши?
- [ ] $\exists \varepsilon > 0\; \forall \delta > 0: |x - x_0| < \delta \Rightarrow |f(x) - a| < \varepsilon$ :: Кванторы переставлены: так записано другое, гораздо более сильное условие.
- [x] $\forall \varepsilon > 0\; \exists \delta > 0: 0 < |x - x_0| < \delta \Rightarrow |f(x) - a| < \varepsilon$ :: Для любого $\varepsilon$ подбирается своё $\delta$.
- [ ] $\forall \delta > 0\; \exists \varepsilon > 0: 0 < |x - x_0| < \delta \Rightarrow |f(x) - a| < \varepsilon$ :: Здесь неверный порядок: сначала задаётся $\varepsilon$, потом ищется $\delta$.
explain: Сначала задаётся произвольная окрестность значения, затем подбирается подходящая окрестность аргумента.

? Что надо сделать, чтобы доказать по Гейне отсутствие предела у функции в точке $x_0$?
- [ ] Найти одну последовательность $x_n \to x_0$ с $f(x_n) = 0$ :: Один предел значений ничему не противоречит.
- [x] Найти две последовательности $x_n \to x_0$, $y_n \to x_0$ с разными пределами $f(x_n)$ и $f(y_n)$
- [ ] Показать, что $f(x_0)$ не существует :: Существование $f(x_0)$ на предел не влияет.
explain: Если бы предел существовал, он был бы одним и тем же вдоль любой последовательности.

? Чему равен предел $\lim\limits_{n \to \infty} f(x_n)$ для $f(x) = \sin\dfrac{1}{x}$ и $x_n = \dfrac{1}{\pi n}$? Введите целое число.
= 0
correct: Имеем $f(x_n) = \sin(\pi n) = 0$ при всех $n$.
wrong: Подставляя $x_n = \dfrac{1}{\pi n}$, получаем $f(x_n) = \sin(\pi n) = 0$, значит предел равен $0$.

? Что гарантирует существование предела $\lim\limits_{x \to x_0} f(x)$ для ограниченности функции?
- [ ] Ограниченность на всей области определения :: Гарантия только локальная.
- [x] Ограниченность в некоторой проколотой окрестности $x_0$ :: Это следует из выбора $\varepsilon = 1$.
- [ ] Ограниченность только в самой точке $x_0$ :: Значение в одной точке не описывает поведение функции вблизи неё.
explain: Теорема о локальной ограниченности утверждает ограниченность в проколотой окрестности точки.

? Чему равно $\delta_\varepsilon$ в доказательстве предела $\lim\limits_{x \to 3} (x^2 - 2x) = 3$ при $\varepsilon = 10$? Введите целое число.
= 1
correct: Здесь $\dfrac{\varepsilon}{5} = 2$, и $\min(1, 2) = 1$.
wrong: Надо взять минимум из $1$ и $\dfrac{\varepsilon}{5} = 2$; он равен $1$.

? Какие утверждения верны для $\lim\limits_{x \to x_0} f(x) = a$ при $a > 0$ и $f(x) \leq g(x)$ в окрестности $x_0$ (если $\lim g$ существует)?
- [x] $\lim\limits_{x \to x_0} g(x) \geq a$ :: Предельный переход сохраняет нестрогое неравенство.
- [x] В некоторой проколотой окрестности $x_0$ верно $f(x) > 0$ :: Следует из теоремы о сохранении знака.
- [ ] $\lim\limits_{x \to x_0} g(x) > a$ :: Строгость неравенства при предельном переходе не сохраняется.
- [ ] $f(x_0) = a$ :: Значение в точке $x_0$ с пределом не связано.
explain: Сохраняются нестрогие неравенства и знак предела (в окрестности), но не строгость и не значение в самой точке.
```
